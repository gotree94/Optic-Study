# 7. 응용 광학계 성능평가

> 3일차 2강 · 휴대폰부터 위성까지, 용도별 평가 포인트

## 7.1 응용 시스템 분류와 평가 초점

| 시스템 | 대표 요구 | 평가 핵심 |
|--------|----------|----------|
| **휴대폰 카메라** | 초소형, 다초점, AI 보정 | MTF, 왜곡, 색수차, 모듈 일관성 |
| **AR/VR 광학계** | 광시야각, 초경량, Eye-box | MTF+Eye-box, 왜곡, 색수차, Eye-relief |
| **인공위성 카메라** | 대구경, 초저온, 장기신뢰성 | 파형오차, 전온도 MTF, 진동·충격 |
| **천체 망원경** | 초대구경, 장시간 추적 | 주경 면형, 추적 정밀도, 장노출 PSF |
| **반도체 노광기** | 나노미터 해상도 | 파형오차(λ/50↓), DOF, 무왜곡, 열 안정 |

## 7.2 휴대폰 카메라 평가

| 항목 | 방법 | 비고 |
|------|------|------|
| MTF | 차트 촬영 (ISO 12233) | 중앙/주변, 다양한 f값 |
| Distortion | 그리드 차트 | 보정 소프트웨어 영향 포함 |
| 색수차(LCA) | 고대비 엣지 | 경계부 색 번짐 |
| 플레어/고스트 | 강광원 시험 | 멀티렌즈 반사 |
| 모듈 일관성 | 라인 샘플링 | 크기·초점 편차 관리 |

## 7.3 AR/VR 광학계 평가

```
   [디스플레이] → [광학계(Pancake 등)] → [눈(Eye-box)]
```

| 항목 | 특이점 |
|------|--------|
| **Eye-box** | 눈이 움직일 수 있는 범위 — MTF와 함께 봄 |
| **Eye-relief** | 눈까지 거리 — 안경 착용 여부 |
| **왜곡(Distortion)** | 소프트웨어 보정 전후 확인 |
| **Mura/균일도** | 디스플레이+광학 통합 |
| **초점(vergence-accommodation)** | 피로감 평가 (동적) |

## 7.4 인공위성 카메라 평가

| 단계 | 평가 내용 |
|------|----------|
| 부품 | 주경/보조경 면형(간섭계), 편심 |
| 모듈 | 저온(-20~-40°C) 파형/MTF |
| 시스템 | 진동·충격 시험 후 재검사 |
| 환경 | 열진공(TVAC), 방사선 내성 |
| 최종 | 지상 시뮬레이션 광원으로 MTF/PSF |

## 7.5 천체 망원경 평가

| 항목 | 방법 |
|------|------|
| 주경 면형 | 대형 간섭계 또는 스캐닝 계측 |
| 추적 정밀도 | 별 추적 카메라, 오프셋 측정 |
| 장노출 PSF | 실제 천체 사진 분석 |
| 대기扰動 보정 | 적외선 광시야각 보정 성능 |

## 7.6 반도체 노광기(DUV/EUV) 평가

| 항목 | 목표 수준 | 방법 |
|------|----------|------|
| 파형오차 | λ/50 이하 (EUV는 皮m급) | 간섭계 |
| 무왜곡(Distortion) | nm급 | 기준 그리드 대비 |
| DOF | 공정 요구 이상 | 포커스 스윕 |
| 열 안정 | pm/°C | 온도 스윕 MTF |
| 광원 균일도 | % 단위 | Illumination uniformity |

## 7.8 정리 — 평가 설계 원칙

1. **용도별 요구 성능 정의** (무엇이 "좋은가"를 먼저 합의)
2. **측정 조건 표준화** (같은 조건에서 비교)
3. **부품 → 모듈 → 시스템** 단계별 검증
4. **환경 변화 전후** 비교 (실제 사용 조건 반영)
5. **데이터 축적** — MTF, 파형, 온도, 진동 이력 관리
