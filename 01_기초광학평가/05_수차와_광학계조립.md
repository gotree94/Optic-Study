# 5. 광학 수차와 광학계 조립

> 2일차 2강 · 렌즈 하나의 결함에서 시스템 전체 성능까지

## 5.1 수차(Aberration)란

> **빛이 "이상적인 점"에 모이지 못하는 현상** 전부를 수차라 한다.

| 이상적인 상 | 실제 상 |
|------------|---------|
| 점 광원 → 한 점에 모임 | 점 광원 → 번진 점 |

### 7가지 세이델 수차 (표)

| # | 수차 이름 | 한눈에 보기 | 주요 원인 |
|---|----------|-----------|----------|
| 1 | 구면수차 | 축상 광선과 주변 광선 초점이 다름 | 구면 렌즈 |
| 2 | 혼장수차 | 상이 깨진 나방처럼 번짐 | 비축상 광선 |
| 3 | 난시(Astigmatism) | 가로/세로 초점이 다름 | 기울어진 광선 |
| 4 | 포면(Petzval)수차 | 상 전체가 휘어짐 | 렌즈 배열 |
| 5 |彗성(Coma) | 혼수차의 비축상 버전 | 주변부 |
| 6 | 지마(Distortion) | 상 왜곡 (통모양/베개모양) | 주변부 |
| 7 | 색수차 | 색별 초점 차 | 분산(Disperssion) |

## 5.2 수차를 "그림"으로 이해

```
[구면수차]           [혼장수차]           [난시]
 초점이 흐려짐        상이 깨짐           가로/세로 분리

   ──●━━━━            ✦ 번짐              |   —
      ↑                ↑                  ↑
   광축 방향         나방 형태           방위별 초점 차
```

| 색수차 타입 | 설명 |
|------------|------|
| 축상 색수차 | 색별 초점 위치 차 → 경계에 색 테두리 |
| 횡색수차 | 색별 상 크기 차 → 주변부 색 번짐 |

## 5.3 수차 보정 방법 요약

| 수차 | 대표 보정법 |
|------|-----------|
| 구면수차 | 비구면 사용, 렌즈 배열 최적화 |
| 혼장/난시 | 대칭적 배치, 주변부 최적화 |
| 포면수차 | 렌즈 간 분산·배열 조정 |
| 색수차 | 이중초점(Achromat), 분산 재료 배합 |
| 지마 | 어플레어(aperture) 위치, 시야각 제어 |

## 5.4 광학계 조립(Alignment) 기초

### 조립이 성능을 좌우한다

```
   [완벽한 렌즈] + [조잡한 조립] = [나쁜 이미지]
```

### 조립 검사 항목

| 항목 | 측정 | 장비 |
|------|------|------|
| **동심(Decenter)** | 렌즈 중심-축 정렬 | 정심기, 간섭계 |
| **기울기(Tilt)** | 표면 기울기 오차 | 간섭계, 자동 정렬 |
| **간격(Spacing)** | 렌즈 사이 거리 | 캘리퍼, 간섭계 |
| **축 정렬** | 광축-기계축 | 정렬 자구 + 간섭계 |

### 조립 공정 예시

```
[부품 검사] → [1차 조립(거친 정렬)] → [간섭계 정렬] → [본드/나사 고정] → [최종 MTF 검사]
```

| 고정 방식 | 장점 | 단점 |
|-----------|------|------|
| 나사/피팅 | 재조립 가능 | 진동에 취약 |
| UV 본드 | 빠른 고정, 정밀 | 재작업 어려움 |
| 적외선 본드 | 강한 접착 | 열 영향 주의 |

## 5.5 실무 시사점
- **수차 보정은 설계에서 끝나지 않는다** — 조립 오차가 수차를 다시 만든다.
- 조립 검사는 **간섭계 파형 + MTF**를 함께 봐야 신뢰도가 높다.
- 대구경·위성계는 **온도·중력 변화 조립 검사**까지 요구.
