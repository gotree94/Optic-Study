# 2. 광학 렌즈와 거울 가공 및 시험

> 1일차 2강 · 구면 렌즈/거울의 공정과 검사 항목

## 2.1 렌즈 가공 공정 흐름

```
[블랭크 절단] → [연삭(그라인딩)] → [연마(Polishing)] → [코팅] → [최종 검사]
   ● 블랭크        ● 굵은 연삭           ● 정밀 연마         ● AR/HR    ● 면형/MTF
     절단           ● 정밀 연삭           ● 화학연마(FAP)      ● 기타      ● 치수
```

| 공정 | 목표 | 주요 장비 | 대표 정밀도 |
|------|------|----------|-----------|
| 절단 | 블랭크 형상 확보 | 다이아몬드 톱 | ±0.1 mm |
| 연삭 | 곡률 형성, 두께 확보 | 펠렛 그라인더 | 수 µm |
| 연마 | 광택, 최종 면형 | 폴리셔, FAP | 수 Å(Ångström) |
| 코팅 | 반사율/투과율 제어 | 진공 코팅기 | 막 두께 ±1~2% |

## 2.2 거울 가공 공정

| 방식 | 특징 | 적용 |
|------|------|------|
| 연마식(Pitch Polishing) | 전통적, 대구경 가능 | 천체망원경 주경 |
| CNC 연삭/연마 | 비구면·대구경 효율 | 위성 거울, 천체 |
| 이온빔 가공(IBF) | nm급 보정 | 최종 면형 보정 |
| 정밀 주조/복합소재 | 경량화 | 위성, 항공 |

## 2.3 가공 후 시험 항목 (표 중심)

| 시험 항목 | 측정 대상 | 장비 | 합격 기준 예시 |
|-----------|----------|------|--------------|
| **곡률반경** | 렌즈/거울의 곡률 | 간섭계, 초점계 | 설계값 ±0.1% |
| **면형오차(PV/RMS)** | 표면 정밀도 | 피토-스태먼트 간섭계 | λ/4 PV 이하 |
| **중심두께** | 렌즈 두께 | 마이크로미터, 초음파 | ±10 µm |
| **편심(탈중심)** | 광축-기계축 정렬 | 정심기(centroid meter) | 수 arcsec |
| **각도 오차** | 프리즘 각, 쐐기각 | 각도계, 간섭계 | 수 arcsec~분 |
| **표면 흠집(LIDT)** | 레이저 손상 역치 | LIDT 테스터 | 애플리케이션별 |
| **투과율/반사율** | 광학 특성 | 분광광도계 | 설계값 ±0.5% |

## 2.4 핵심 검사 원리: "간섭계로 보는 면형"

```
    Reference 표준면          가공된 렌즈 표면
         │                        │
         ▼                        ▼
    ─────────────  간섭 무늬(Fringe) 생성  ─────────────
         
    무늬가 직선 ↔ 평평/원만한 곡면
    무늬가 휘어짐 ↔ 오차 존재 (등고선처럼 읽음)
```

> **그림 요약**: 간섭계는 "빛의 파장을 자로 삼아" 표면을 읽는 장비다.

## 2.5 실무 체크리스트

- [ ] 가공 전: 블랭크 내부 응력, 기포 확인
- [ ] 중간 연삭 후: 곡률/두께 검사로 연마 여유 확보
- [ ] 연마 후: 간섭계 면형 + 편심 동시 확인
- [ ] 코팅 후: 반사율/투과율 측정 (코팅 영향 반영)
- [ ] 출하 전: MTF 또는 파형 오차 통합 리포트
