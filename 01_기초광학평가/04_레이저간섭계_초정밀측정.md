# 4. 레이저 간섭계와 초정밀 측정

> 2일차 1강 · 나노미터 세계를 읽는 도구

## 4.1 간섭계의 기본 원리 (수식 없이)

```
레이저 광원
    │
    ├──→ [참고 거울]  ──┐
    │                    ├── 합성 → 간섭무늬(Fringe) → 카메라
    └──→ [측정 대상]  ──┘
```

| 개념 | 비유 |
|------|------|
| 파장(λ) | 자의 눈금 (예: HeNe 레이저 632.8 nm) |
| 간섭무늬 | "지형도의 등고선" — 높이차를 색으로 보는 것 |
| PV 오차 | 봉우리와 골짜기의 높이차 |
| RMS 오차 | 표면 전체의 평균적인 울퉁불퉁함 |

> **한 줄 요약**: 간섭계는 **빛의 파장을 자로 삼아 표면 높이를 지도로 그리는 장비**다.

## 4.2 주요 간섭계 유형

| 유형 | 구조 | 대상 | 정밀도 |
|------|------|------|--------|
| **피토-스태먼트(Fizeau)** | 공통 경로, 단순·안정 | 거울, 렌즈 표면 | λ/20 이상 |
| **트와이만-가이어(Twyman-Green)** | 분리 경로, 다양한 검사 | 프리즘, 각도, 병렬도 | λ/20 이상 |
| **FPG(파이버 간섭계)** | 광섬유 경로 | 소형, 현장 측정 | nm급 |
| **스캐닝 간섭계** | 점별 스캔 | 비구면, 프리폼 | µm 이하 |

## 4.3 초정밀 측정 체계

### 계층 구조

```
    국가 표준 (KRISS 등)
           │
           ▼
    작업 간섭계 (Workshop Interferometer)
           │  보정 간섭계로 교정
           ▼
    생산 라인 검사기
           │
           ▼
    제품 (렌즈/거울)
```

| 단위 기관 | 역할 |
|-----------|------|
| **KRISS** (한국) | 국가 표준, 파장 기준 |
| **PTB** (독일), **NIST** (미국) | 국제 교차 검증 |
| **제조사 보정실** | 라인별 상대 보정 |

## 4.4 초정밀 측정에서 흔한 오류 원인

| 원인 | 증상 | 대응 |
|------|------|------|
| **온도 변화** | 측정 중 무늬 흔들림 | 항온 실내, 안정화 시간 확보 |
| **진동** | 무늬 흔들림·블러 | 공기부상 테이블, 지반 분리 |
| **대기 변동** | 무늬 지터 | 덮개, 오염 관리 |
| **간섭계 정렬 오차** | 허위 오차, 카리오코(Carrier) 오차 | 광축 정렬, 캐리어 설정 |
| **표준면 오차** | 측정값 왜곡 | 표준면 정기 보정 |

## 4.5 검사 리포트 이해하기

| 항목 | 의미 | 예시 |
|------|------|------|
| PV | 최대-최소 오차 | λ/10 (≈63 nm) |
| RMS | 통계적 평균 오차 | λ/50 (≈13 nm) |
| Power | 구면 성분(전체 곡률 오차) | λ/8 |
| Irregularity | Power 제거 후 잔여 오차 | λ/20 |
| Astig | 난시 성분 | λ/15 |

> **PV vs RMS**: PV는 "최악의 점", RMS는 "평균 품질" — 둘 다 봐야 한다.

## 4.6 실무 체크리스트
- [ ] 간섭계 측정 전 **온도 안정화**(30분 이상)
- [ ] 표준면(참고면) **정기 보정 이력** 확인
- [ ] 대상 물체 **내부 응력 방출** 후 측정
- [ ] 측정 조건(온도·습도·시간)을 리포트에 기록
- [ ] PV·RMS·Power·Irregularity **4종 세트**로 판단
