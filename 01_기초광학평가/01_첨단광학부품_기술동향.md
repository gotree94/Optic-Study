# 1. 첨단 광학부품 및 광학계 기술 동향

> 1일차 1강 · 수식 없는 그림·표 중심 설명

## 1.1 왜 "첨단 광학부품"인가

| 시대 | 대표 광학계 | 요구 성능 | 핵심 기술 |
|------|------------|----------|----------|
| 1980s | 필름 카메라, 단순 렌즈 | 해상도 중심 | 구면 렌즈 가공 |
| 1990s | CD/DVD 렌즈 | 1µm 수준 추적 | 비구면 몰딩 |
| 2000s | 휴대폰 카메라, DSC | 소형·고해상도 | 플라스틱 비구면, 접착 렌즈 |
| 2010s | 스마트폰 멀티카메라, AR/VR | 광각·초소형 | 자유곡면(Freeform), 광학계-센서 통합 |
| 2020s~ | 인공위성, 반도체 노광, LiDAR | 초정밀·초대형 | SiC/CNC 가공, 간섭계 검사, AI 보정 |

## 1.2 첨단 광학부품 분류

```
                    광학부품
          ┌────────────┼────────────┐
       굴절계        반사계        복합계
    (렌즈 계열)   (거울 계열)   (렌즈+거울)
          │            │            │
   ┌──────┼──────┐     │      ┌─────┼─────┐
  구면  비구면  자유곡면  구면/비구면  카세그레인  광축계(Schmidt 등)
```

| 부품 유형 | 특징 | 대표 적용 |
|----------|------|----------|
| **구면 렌즈** | 가공·검사 쉬움, 비용 낮음 | 일반 카메라, 조명 |
| **비구면 렌즈** | 수차 적음, 소형화 가능 | 휴대폰 카메라, 머리카락 구경(LCD) |
| **자유곡면(Freeform)** | 비축 대칭, 자유 설계 | AR/VR 광학계, 차량용 헤드램프 |
| **대구경 거울** | 무게·변형 관리 핵심 | 천체망원경, 인공위성 |
| **정밀 기판·웨이퍼 렌즈** | 면형 오차 나노미터급 | 반도체 노광 렌즈 (DUV/EUV) |

## 1.3 기술 동향 3대 키워드

### ① 초소형·다기능
- 휴대폰 카메라: 7~8장 렌즈로 접사+광각+망원 동시 구현
- 렌즈 1장에 여러 기능(굴절+회절+편광)을 넣는 **계면 기능화**

### ② 초정밀·초대형
- 반도체 노광 렌즈: 파장의 1/50 이하 면오차 요구
- 인공위성 카메라: 지상 해상 0.3m급, 무중력·온도변화 대응

### ③ 신소재·신공법
| 소재 | 장점 | 용도 |
|------|------|------|
| 칼코게나이드(Chalcogenide) | 적외선 투과 | 열화상, 자동차 LiDAR |
| SiC | 강성↑, 열팽창↓ | 대구경 위성 거울 |
| 유리 정밀 몰딩(GGM) | 비구면 대량생산 | 휴대폰, 자동차 |
| 3D 프린팅 광학 | 형상 자유 | 프리폼, 맞춤형 기기 |

## 1.4 성능 검사 기술의 중요성

```
[가공] → [검사] → [평가] → [출하]
  │        │        │
  │        │        └─ MTF, 이미지 품질
  │        └────────── 면형, 편심, 조도
  └─────────────────── 공정 파라미터 보정
```

> **핵심**: "잘 만들었다"가 아니라 "정확히 측정·증명했다"가 곧 품질이다.
