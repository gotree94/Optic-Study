# 6. 광학 성능의 언어: MTF

> 3일차 1강 · Modulation Transfer Function 측정과 표준

## 6.1 MTF란

| 단어 | 의미 |
|------|------|
| **Modulation** | 명암 대비 (검은 줄과 흰 줄의 뚜렷함) |
| **Transfer** | 대상(렌즈)이 이 대비를 얼마나 "전달"하는지 |
| **Function** | 공간주파수(줄기 빈도)에 따른 변화 함수 |

```
입력 (Test Chart)                  출력 (렌즈를 통해 본 상)
┌────────────────┐                ┌────────────────┐
││││││││││││││││││  ── 렌즈 ──→  ││  ││  ││  ││    ← 흐려짐
└────────────────┘                └────────────────┘
  뚜렷한 대비                         대비 감소
```

> **한 줄 요약**: MTF는 **"렌즈가 선을 얼마나 선답게 전달하는가"** 를 0~1로 나타낸 곡선.

## 6.2 MTF 곡선 읽는 법

```
MTF
1.0 ┤●━━━━━━━━━━┓
    │             ┗━━━━━━━┓
0.5 ┤                      ┗━━━━━━┓
    │                              ┗━━━━●
0.0 ┼────┬────┬────┬────┬────┬────┬──→ 공간주파수 (lp/mm)
    0   10   20   30   40   50   60
```

| 구간 | 의미 |
|------|------|
| 0 lp/mm | 균일한 명암 (전체 밝기) — 항상 1 |
| 낮은 주파수 | 큰 사물輪廓, 굵은 선 — 대비 |
| 높은 주파수 | 잔손상, 머리카락 — 해상도 |
| **MTF50** | 50%로 떨어지는 주파수 — **감각적 선명도와 상관 최고** |
| 컷오프 | 0이 되는 지점 — 물리적 해상도 한계 |

## 6.3 MTF 계측 방식

| 방식 | 대상 | 특징 |
|------|------|------|
| **슬릿 스캔(직접)** | 렌즈 단독 | 슬릿 이미지 스캔, 표준적 |
| **MTF 카메라** | 카메라 모듈 | 차트 촬영 후 소프트웨어 분석 |
| **간섭 MTF** | 고정밀 렌즈 | 파형에서 이론 MTF 도출 |
| **엣지(Edge) 측정** | 모듈·시스템 | 사각엣지 이미지 → SFR 산출 |

### 측정 조건 (표준화 핵심 요소)

| 조건 | 왜 중요한가 |
|------|-----------|
| 대상 차트 Contrast | MTF 값과 직결 |
| f/#, 조리개 | 수차·회절 영향 |
| 파장(백색/단색) | 색수차 반영 여부 |
| 시야각(축상/주변) | 주변부 성능 확인 |
| 초점 거리/배율 | 조건 불일치 시 비교 불가 |
| 조명 균일도 | 차트 자체 오차 |

## 6.4 MTF 표준화 동향

| 표준/기관 | 내용 |
|-----------|------|
| **ISO 12233** | 디지털 카메라 해상도/MTF 측정 |
| **ISO 9039** | 광학계 광학적 전달함수 |
| **ISO 15529** | 편광 광학계 MTF |
| **VDA(Robust Engineering)** | 자동차 카메라 평가 |
| **EMVA 1288** | 센서+광학 통합 성능 |

> **실무 포인트**: 측정 조건이 다르면 MTF 수치 비교 자체가 무의미. **"같은 조건, 같은 방식"** 이 표준의 핵심.

## 6.5 MTF와 다른 지표 관계

| 지표 | 관계 |
|------|------|
| 해상도(resolving power) | MTF=0 지점 — MTF의 일부 정보 |
| 파형오차(Strehl) | 저주파 성능과 상관 |
| PSF | MTF의 "점 확산함수" 원본 |
| 퍼셉추얼(perceptual) 화질 | MTF50, MTF1000 등 가중치 |

## 6.6 실무 체크리스트
- [ ] 측정 전 **대상 차트 Contrast 정확도** 확인
- [ ] 축상·주변부(상/하/좌/우) **4방향** 측정
- [ ] 적절한 주파수 대역 선택 (앱별 중점: 휴대폰 1~30 lp/mm, 위성 등)
- [ ] 광원 파장 조건 명시 (백색광/단색)
- [ ] 온도·진동 환경 관리 (고정밀계)
