# 기초광학평가 (Basic Optical Evaluation)

> 단일 렌즈/거울 가공부터 대구경 인공위성 카메라까지, 검사·평가 기술을 **수식 없이 그림·표 중심으로** 쉽게 설명하는 3일 과정

## 강의 개요

| 항목 | 내용 |
|------|------|
| **강의방법** | 복잡한 수식 회피, 그림·표 중심 설명 |
| **강의대상** | 이공계 대학 졸업자, 광산업 실무자, 광학제조 품질관리 담당자, 광학부품/모듈 성능평가 실무자 |
| **기간** | 3일 (일 10:00~18:00 기준) |
