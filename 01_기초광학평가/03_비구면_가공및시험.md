# 3. 비구면 렌즈와 거울 가공 및 시험

> 1일차 3강 · 구면 대비 비구면의 이점, 가공·검사 차이

## 3.1 비구면이란

| 구분 | 구면(Spherical) | 비구면(Aspheric) |
|------|----------------|-----------------|
| 형상 | 중심에서 일정한 곡률 | 중심에서 갈수록 곡률이 변함 |
| 장점 | 가공·검사 쉬움, 저렴 | 수차 대폭 감소, 장수 렌즈 대체 |
| 단점 | 구면수차 발생 | 가공·검사 비용↑ |
| 적용 | 일반 렌즈, 대구경 거울 초벌 | 휴대폰, 머리카락 구경, 적외선 |

```
[구면 렌즈 3장]               →    [비구면 렌즈 1~2장]
  수차 보정 위해 개수 증가              소형·경량·저수차
```

## 3.2 비구면 가공 방법

| 방식 | 원리 | 생산성 | 비고 |
|------|------|--------|------|
| **정밀 그라인딩/연마** | CNC로 점별 가공 | 낮음 | 대구경, 소량, 거울 |
| **유리 정밀 몰딩(GGM)** | 렌즈 소재를 금형에 눌러 성형 | 높음 | 휴대폰, 대량 양산 |
| **플라스틱 몰딩** | 사출/압축 성형 | 매우 높음 | 저가·초소형 |
| **이온빔 가공(IBF)** | 이온으로 표면 증발·보정 | 매우 낮음 | 최종 nm 보정 |
| **DLP/SLA 3D 프린팅** | 적층 소재 성형 | 중간 | 프리폼, 프로토타입 |

### 비구면 계수(식)
> 수식 대신 **"구면에서 벗어난 양"** 을 계수로 표현한다고 이해하면 충분합니다.

```
비구면 깊이  =  r² / (R·(1+√(1-(1+k)·(r/R)²)))
                 ↑ k가 -1이면 구면, 이 외는 비구면
```

| k 값 | 형상 |
|------|------|
| k = 0 | 구면 |
| −1 < k < 0 | 타원체 |
| k = −1 | 포물면 |
| k < −1 | 쌍곡면 |

## 3.3 비구면 검사 방법

| 시험 항목 | 장비/방법 | 핵심 포인트 |
|-----------|----------|-----------|
| **비구면 파라미터 검사** | 간섭계 + CGH(컴퓨터 간섭계) | 계수 오차 확인 |
| **표면 오차 맵** | 스캐닝 간섭계, 스텝계측 | PV/RMS 맵 시각화 |
| **절대 측정** | 절대 간섭계(Calibrell 등) | 간섭계 표준면 오차 보정 |
| **비접촉 3D** | 형태계측기, 초음파 | 대형·연약 소재 |
| **MTF/초점 검사** | MTF 계측기, 카메라 모듈 | 조립 후 최종 성능 |

### CGH(Computer Generated Hologram) 방식 개요

```
[간섭계 광원] → [CGH 회절광학] → [비구면 표면] → 반사/투과 → 간섭무늬
                         ↑
              이상적인 비구면 파형을 생성하는 "가상 표준면"
```

## 3.4 구면 vs 비구면 검사 비교표

| 항목 | 구면 | 비구면 |
|------|------|--------|
| 표준면 | 단순 구면 표준면 | CGH 또는 스캔 방식 |
| 검사 시간 | 짧음 | 길다 (점별/보정) |
| 장비 비용 | 보통 | 높음 |
| 합격 판정 | PV/RMS 단일값 | 오차 맵 + 계수 |
| 조립 영향 | 편심만 관리 | 편심+계수 오차 동시 관리 |

## 3.5 실무 팁
- 비구면 **가공 난이도는 검사 난이도와 한 쌍**. 설계 시 검사 장비 능력을 먼저 확인.
- 몰딩 비구면: 금형 오차가 렌즈에 그대로 전사 → **금형 간섭계 검사**가 1차 관문.
- 조립 시 구면보다 편심·기울기(tilt)에 더 민감 → 적합한 조립 자구(adjuster) 선택 필요.
