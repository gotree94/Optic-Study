# 7. 최신 광기계 설계 및 해석 동향

> Day3 · 미래 기술과 실무 트렌드

## 7.1 주요 동향 요약

| 동향 | 핵심 | 영향 |
|------|------|------|
| **초경량·초소형** | AR/VR, 휴대폰 | 정밀도↑, 비용↓ |
| **자유곡면·프리폼** | 비축 대칭 | 기계 정렬 복잡 |
| **적외선·열화상** | 자동차, 국방 | 소재·검사 특수 |
| **대구경·위성** | 천체, 관측 | 중력·열·진공 |
| **반도체 광학** | EUV/DUV | 나노미터 기계 |
| **AI·자동화** | 설계·검사 | 데이터 기반 최적화 |

## 7.2 자유곡면(Freeform) 광기계

| 항목 | 내용 |
|------|------|
| **광학** | 비축 대칭, 자유 설계 |
| **기계** | 비대칭 마운트, 정렬 DOF↑ |
| **검사** | CGH 등 특수 간섭계 |
| **적용** | AR/VR, 헤드램프, 안경 |

## 7.3 적외선 광기계 동향

| 소재 | 특징 | 광기계 고려 |
|------|------|-----------|
| **Ge, Si** | 높은 n | 열·기계 강성 |
| **Chalcogenide** | 비정질 | 열팽창 |
| **ZnSe/ZnS** | 광학창 | 취성 |

- **열화상**: -40~+80°C 성능 유지 → **아파칼 설계 필수**
- **자동차 LiDAR**: 충격·진동 내성, 대량 생산성

## 7.4 위성·대구경 광기계 동향

| 기술 | 내용 |
|------|------|
| **경량화** | SiC, CFRP 복합 |
| **저온 정렬** | 사용 온도에서 정렬 |
| **무중력 시험** | 중력 변형 보정 |
| **자기적 정렬** | kinematic 재현성 |

## 7.5 반도체 노광 광기계 동향

| 요구 | 내용 |
|------|------|
| **나노미터 정렬** | nm~pm급 |
| **열 안정** | 0.01°C급 관리 |
| **진공·저온** | EUV 환경 |
| **실시간 보정** | 센서+액추에이터 |

## 7.6 AI·자동화 적용

| 분야 | 적용 |
|------|------|
| **설계** | 광기계 형상 최적화(GA, 신경망) |
| **해석** | 메시 자동화, surrogate 모델 |
| **검사** | 이미지 기반 편심 자동 계측 |
| **유지보수** | 이상 감지, 예측 정비 |

## 7.7 실무자를 위한 시사점

1. **다학제 통합**: 광학·기계·열·소재·제어 동시 고려
2. **시뮬레이션 우선**: FEA·광학 연성으로 리스크 사전 차단
3. **표준·인증**: 산업별(위성·자동차·의료) 인증 이해
4. **지속 학습**: 신소재·AI·자동화 도구 숙지
