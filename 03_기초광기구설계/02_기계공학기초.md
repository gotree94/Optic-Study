# 2. 광기계 관련 기계공학 기초 이론

> Day1 · 광기계에 필요한 기계공학 핵심 개념

## 2.1 정적·동적 힘과 모멘트

| 개념 | 정의 | 광기계 예 |
|------|------|----------|
| **하중(Load)** | 힘, 분포하중 | 렌즈 무게, 바람 |
| **모멘트** | 힘 × 거리 | 거울 지지대 비틀림 |
| **반력·결합력** | 지지점 힘 | 마운트 볼트 |

## 2.2 응력·변형(Stress-Strain)

```
응력 σ = F / A
변형 ε = ΔL / L
```

| 항목 | 용어 | 광기계 의미 |
|------|------|-----------|
| **탄성계수(E)** | 강성 | 처짐량 결정 |
| **포아송비(ν)** | 횡변형 | 지지 구조 설계 |
| **항복강도** | 영구변형 한계 | 안전율 |
| **피로(Fatigue)** | 반복하중 손상 | 진동 환경 |

## 2.3 재료 선택 기초

| 재료 | CTE (µm/m·K) | 장점 | 광기계 용도 |
|------|--------------|------|-----------|
| **알루미늄** | ~23 | 가볍고, 가공 쉬움 | 일반 마운트, 구조 |
| **강철** | ~12 | 강성↑ | 대형 지지 |
| **Invar** | ~1.2 | 저팽창 | 정밀 기준, 위성 |
| **SiC** | ~4 | 강성↑, 열안정 | 대구경 거울 |
| **Invar/Al 복합** | — | 열 매칭 | 렌즈 바렐 |
| **유리(레퍼런스)** | ~7~9 | 광학 기준 | 거울 기판 |

> **핵심**: **CTE 불일치 → 온도 변화 시 편심·응력 발생** — 재료 선택의 1순위 검토 사항.

## 2.4 열전달·열변형

| 개념 | 식(개념) | 광기계 의미 |
|------|---------|-----------|
| **전도** | ΔT → 온도 구배 | 대형 거울 내부 |
| **대류** | 공기 흐름 | 실내 광학계 |
| **복사** | T⁴ 방사 | 위성, 진공 |
| **열팽창** | ΔL = α·L·ΔT | 렌즈 간격, 거울 sag |

### 열변형 예시 (개념)
- 길이 100 mm, α=23 ppm/K, ΔT=10 K → ΔL ≈ 23 µm
- 광학 허용 오차는 수 µm대일 수 있음 → **Invar, 열 보정 설계 필요**

## 2.5 진동·구조 역학 기초

| 개념 | 의미 | 광기계 대응 |
|------|------|-----------|
| **자연진동수** | 공진 주파수 | 외부 진동과 분리 |
| **강성(k)** | 힘-변위 상수 | 정렬 유지 |
| **감쇠** | 진동 에너지 소산 | 댐퍼, 본드 |
| **충격 계수** | 순간 가속 | 볼트·지지 강도 |

```
자연진동수 f_n ∝ √(k/m)   → 강성 ↑ 또는 질량 ↓ 로 상향
```

## 2.6 공차 분석(Tolerance Stack-up)

| 방법 | 개요 |
|------|------|
| **최악의 경우(Worst-case)** | 공차 합산 — 보수적 |
| **통계(RSS)** | 제곱합 제곱근 — 현실적 |
| **Monte Carlo** | 난수 시뮬레이션 — 정밀 |

### 광기계 공차 배분 절차
1. 광학 허용 오차(편심·기울기) 도출
2. 기계 부품 공차로 분해 (렌즈, 마운트, 바렐)
3. 조립 공정 공차 반영
4. RSS/시뮬레이션으로 검증, 필요 시 재배분

## 2.7 Day1 정리 — 기계공학이 광기계에 주는 것

- **재료·열·진동·공차**가 광학 성능을 좌우.
- 설계 초기에 **오차 예산과 열 해석**을 병행해야 안정적.
- **강성 vs 질량 vs 비용** 트레이드오프가 항상 존재.
