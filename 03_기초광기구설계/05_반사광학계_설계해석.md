# 5. 반사 광학계의 광기계 설계 및 해석

> Day2 · 거울 기반 광학계의 기계적 설계

## 5.1 반사 광학계 개요

| 구분 | 장점 | 단점 |
|------|------|------|
| **반사계(거울)** | 색수차 없음, 대구경 가능, 무게↓ | 중심 차폐, 정렬 예민 |
| **굴절계(렌즈)** | 중심 개방, 조립 용이 | 색수차, 대구경 어려움 |

## 5.2 대표 반사 광학계

| 유형 | 구조 | 응용 |
|------|------|------|
| **뉴튼** | 오목 주경 + 평면 거울 | 천체망원경 |
| **카세그레인** | 오목 주경 + 볼록 보조경 | 위성, 천체 |
| **리치크레텐** | 두 개의 곡면 | 고해상도 |
| **Schmidt** | 보정판 + 주경 | 광시야 |
| **R-C (Ritchey-Chrétien)** | 두 비구면 | 현대 천체·위성 |

## 5.3 반사계 광기계 설계 과제

| 과제 | 설명 | 대응 |
|------|------|------|
| **주경 처짐** | 대구경 거울 중력 sag | 경량화, 다점 지지, 저온 공정 |
| **보조경 지지** | 스파이더 변형 | 슬림 스파이더, 사전 응력 |
| **열 변형** | 온도 구배 | Invar, SiC, 열 관리 |
| **정렬 유지** | 주경-보조경 상대 위치 | kinematic mount, 조정 자구 |
| **중심 차폐** | 스파이더 diffraction | 최소화 설계 |

## 5.4 대구경 거울 지지 설계

### 지지 방식 비교

| 방식 | 원리 | 대상 |
|------|------|------|
| **단순 엣지 지지** | 가장자리 고정 | 소형 |
| **다점 백 사이드 지지** | 등간격 지지점 | 중대형 |
| **Whiffletree** | 평행 사변형 다단 지지 | 대형, 초정밀 |
| **공압 지지** | 공기압으로 하중 분산 | 초대형 |

### 처짐(Sag) 이해

```
[거울]  →  중력으로 중앙 처짐  →  광학면 오차(포면수차화)
```

- **지지점 수·배치**가 sag 패턴 결정
- FEA로 최적 지지점 찾기 → **Sag 보정 vs 지지 보정**

## 5.5 스파이더(Spider) 설계

| 항목 | 고려 사항 |
|------|----------|
| **개수·두께** | 강성 vs 차폐·회절 |
| **재료** | 경량·저팽창 |
| **접합부** | 열 응력, 진동 |

## 5.6 반사계 정렬 검사

| 항목 | 방법 |
|------|------|
| **거울 중심·기울기** | 간섭계, 정렬 자구 |
| **주-보조경 간격** | 간섭계, 캘리퍼 |
| **공축성** | Autocollimator, 정렬 광원 |
| **최종 파형** | 간섭계, 천체 광원 시험 |

## 5.7 위성 카메라 반사계 특수 고려

| 항목 | 내용 |
|------|------|
| **발사 하중** | 충격·진동 내성 |
| **온도 변화** | TVAC 시험, 열 진공 |
| **장기 안정성** | 재료 노화, 응력 완화 |
| **경량화** | 질량 예산 |
