# 3. 광기계 설계 기초 이론

> Day2 · 광학 부품을 지지·정렬하는 구조 설계 원리

## 3.1 광기계 설계 절차

```
[광학 요구] → [오차 예산] → [지지·마운트 개념] → [재료·구조] → [해석·검증] → [제작성 검토]
```

## 3.2 오차 예산(Error Budget) 수립

| 오차 원인 | 기여 예 | 허용치 배분 |
|-----------|---------|-----------|
| 렌즈 제작 편심 | µm~십µm | 30~40% |
| 렌즈-마운트 조립 | µm | 20~30% |
| 마운트-바arel | µm~십µm | 20~30% |
| 온도·중력 | 환경별 | 나머지 |

> **목표**: 시스템 MTF/파형 허용치를 각 구성 요소에 합리적으로 분배.

## 3.3 렌즈 마운트 설계

| 방식 | 구조 | 장점 | 단점 |
|------|------|------|------|
| **드롭인** | 렌즈를 바렐에 떨어뜨림 | 조립 간단 | 편심 우려 |
| **Shim/링** | 간격 조정 | 정밀 조정 | 부품 수↑ |
| **스프링 프리로드** | 탄성 지지 | 열팽창 흡수 | 장기 안정성 |
| **접착(본드)** | UV/에폭시 | 경량, 정밀 | 재조립 어려움 |
| **메카니컬 클램프** | 나사·피팅 | 재조립 가능 | 응력 주의 |

### 렌즈 지지 원칙
- **면 접촉** 아닌 **점/선 접촉**으로 응력 집중 피함
- 렌즈 **가장자리 지지**, 광학면 접촉 금지
- 렌즈-금속 **CTE 매칭** 또는 유기 구조

## 3.4 거울 마운트 설계

| 항목 | 고려 사항 |
|------|----------|
| **지지 방식** | 3점, kinematic, 고정+유기 |
| **처짐(Sag)** | 대구경 거울 중력 변형 |
| **각도 조정** | 피에조, 나사, 웨지 |
| **열 응력** | 거울-마운트 CTE 차이 |
| **진공** | outgassing, 열전달 변화 |

### Kinematic Mount 원리

```
 6DOF 완전 제어, 응력 없는 지지
 3점 지지(예: V-groove + ball + flat)로 안정적 재현성
```

## 3.5 정렬 자구(Alignment Mechanism)

| 자구 | 제어 DOF | 정밀도 | 응용 |
|------|---------|--------|------|
| 나사 조정 | 2~3축 | µm~십µm | 일반 |
| 웨지/피치 | 각도 | arcsec | 거울 |
| 피에조 액추에이터 | nm급 | nm | 정밀 |
| 틸팅 스테이지 | 2축 | sub-µrad | 간섭계 |

## 3.6 구조 강성·자연진동수

| 목표 | 방법 |
|------|------|
| 정렬 유지 | 강성↑, cantilever 단축화 |
| 공진 회피 | f_n > 외부 진동 대역 |
| 경량화 | 중공, 알루미늄, 복합소재 |
