# 1. 광기계 서론 및 기하광학 이론

> Day1 · 광학과 기계가 만나는 지점

## 1.1 광기계(Opto-Mechanics)란

> 광학 성능을 **기계적으로 구현·유지·보호**하는 분야.

| 광학 설계 | 광기계 설계 |
|-----------|-----------|
| 렌즈·거울 형상, 배치 | 지지, 정렬, 고정, 환경 대응 |
| 이상적인 광선 추적 | 하중·열·진동에서 위치 유지 |
| MTF, 수차 | 편심·기울기·변형 허용치 |

## 1.2 광기계 설계 목표

1. **정렬 유지**: 광학 부품 위치·방향을 오차 한계 내에서 유지
2. **환경 내성**: 온도·진동·충격·진공·중력 변화 대응
3. **조립·유지보수**: 셋업·캘리브레이션·분해 가능
4. **경량·강성**: 시스템 요구에 맞는 재료·구조
5. **비용·제작성**: 가공·조립 공정 현실성

## 1.3 기하광학 기초

### 광선 다이어그램 규약
| 기호 | 의미 |
|------|------|
| 실선 | 실제 광선 |
| 점선 | 보조선(축, 법선) |
| 화살표 | 전달 방향 |

### 기본 법칙

| 법칙 | 내용 | 광기계 의미 |
|------|------|-----------|
| **직진** | 균일 매질에서 직선 진행 | 광축 정의 |
| **반사** | 입사각=반사각 | 거울 각도 오차 2배 효과 |
| **굴절(Snell)** | n1·sinθ1 = n2·sinθ2 | 렌즈 위치 오차 |
| **광로의 가역성** | 반대 방향 동일 | 역추적·정렬 |

### 거울 오차의 2배 효과

```
거울을 δ 각도만큼 기울이면:
  반사 광선은 2δ 만큼 꺾임
```

> **실무**: 거울 마운트의 각도 정밀도는 렌즈보다 **2배 엄격**해야 함.

## 1.4 광학 좌표계·기준

| 개념 | 정의 |
|------|------|
| **광축(Optical Axis)** | 대칭축 |
| **瞳(Entrance/Exit Pupil)** | 빛 입장/퇴장 구경 |
| **프리즘/거울 fold** | 경로 변경 시 기준면 |
| **Datums** | 기계 기준면·구멍 (조립 정렬) |

## 1.5 오차 원인 분류

```
        광기계 오차
   ┌─────────┼─────────┐
  정적      동적      환경
 (제작·조립) (진동·충격) (온도·중력·진공)
```

| 원인 | 예 | 대응 |
|------|-----|------|
| 제작 공차 | 렌즈 두께, 거울 평면도 | 공차 배분 |
| 조립 편심 | 렌즈-축 정렬 | 정렬 자구 |
| 온도 변화 | 재료 CTE 불일치 | CTE 매칭, 유기 |
| 중력 처짐 | 대구경 거울 sag | 지지 구조 |
| 진동 | 공진, 피로 | 강성·감쇠 |

## 1.6 Day1 정리 — 광기계 사고방식

- 광학 성능은 **기계 오차로 풀린다** — 설계 단계에서 오차 예산(error budget) 필요.
- 거울은 **각도 오차 2배**, 렌즈는 **위치·기울기** 오차가 핵심.
- 기하광학이 광기계의 **공통 언어**.
