# 4. 유한요소 해석(FEA)을 통한 광기계 해석

> Day2 · 수치해석으로 구조·열·진동 검증

## 4.1 FEA란

> 복잡한 구조를 **작은 요소(finite element)로 분해**하여 수치적으로 응력·변형·온도·진동을 푸는 방법.

```
[실제 구조] → [요소 분해(Mesh)] → [경계조건·하중] → [연립방정식 풀이] → [결과(변형·응력·온도)]
```

## 4.2 광기계에서의 FEA 활용

| 해석 유형 | 광기계 질문 | 결과 활용 |
|-----------|-----------|----------|
| **정적 구조** | 하중·중력에서 처짐? | 거울 sag, 렌즈 편심 |
| **열 해석** | 온도 변화 시 변형? | 열팽창, 온도 구배 |
| **열-구조 연성** | 온도+하중 동시? | 위성, 고출력 |
| **모달(진동)** | 자연진동수? | 공진 회피 |
| **하모닉/랜덤 진동** | 진동 내성? | MIL-STD 등 |
| **충격** | 낙하·발사? | 강도 검증 |

## 4.3 광기계 FEA 전략

### 3단계 접근

| 단계 | 목적 | 모델 단순화 |
|------|------|-----------|
| 1. 1D/2D | 빠른 예비 | 빔, 축대칭 |
| 2. 3D 단순 | 지지 구조 검토 | 간소화 메시 |
| 3. 3D 정밀 | 광학면 변형 | 세밀 메시, 연성 |

### 광학 연성(Optical Integration)
- FEA 변형을 **광학면 계수(Power, Astig 등)로 전환**
- Zemax/Code V와 연동하여 MTF 영향 평가

## 4.4 대표 결과 해석

| 결과 | 광기계 의미 |
|------|-----------|
| **변형(Displacement)** | 광학 부품 위치 변화 |
| **응력(Stress)** | 강도·피로 안전 확인 |
| **온도(Temperature)** | 열 구배, 변형 예측 |
| **모드 형상(Mode shape)** | 취약 방향 확인 |
| **자연진동수** | 외부 진동과 분리 여부 |

## 4.5 해석 오류 원인과 대응

| 오류 원인 | 증상 | 대응 |
|-----------|------|------|
| **경계조건 과잉 구속** | 응력 과대 | 실제 지지 방식 모사 |
| **메시 부족** | 결과 불안정 | 수렴 시험, 세분화 |
| **재료 상수 오류** | 전체 틀림 | 온도 의존성 반영 |
| **하중 과소 추정** | 안전하게 과소 | 실제 환경 반영 |
| **비선형 누락** | 대변형 오류 | 필요 시 비선형 |

## 4.6 광기계 해석 검증(Validation)

| 방법 | 내용 |
|------|------|
| **이론 대조** | 단순형(빔, 판) 해석식과 비교 |
| **간섭계 실측** | 해석 vs 실제 파형 비교 |
| **스트레인 게이지** | 응력 실측 |
| **진동 실측** | 가속도계, 레이저 다이오드 |

## 4.7 FEA 리포트 체크리스트

- [ ] 안전율·허용치 대비 판정
