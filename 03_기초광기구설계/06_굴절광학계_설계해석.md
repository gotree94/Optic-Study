# 6. 굴절 광학계의 광기계 설계 및 해석

> Day3 · 렌즈 기반 광학계의 기계적 설계

## 6.1 굴절 광학계 광기계 과제

| 과제 | 설명 | 대응 |
|------|------|------|
| **렌즈 편심** | 광축-렌즈 중심 정렬 | 정심, shims |
| **렌즈 기울기** | 표면 tilt | 정렬 자구 |
| **렌즈 간격** | Spacing 오차 | 바렐 공차, shim |
| **열 변형** | 렌즈-금속 CTE | 유기, CTE 매칭 |
| **응력** | 본드·클램프 응력 | 점 지지, 본드 조건 |
| **바arel 처짐** | 긴 바렐 sag | 지지점, 경량화 |

## 6.2 렌즈 바렐 설계 기초

### 구성 요소

```
[렌즈1] - [Spacer] - [렌즈2] - [Spacer] - [렌즈3] ... - [Retainer Ring]
   └──────────────── 바렐(Barrel) ─────────────────┘
```

| 부품 | 역할 | 재료 예 |
|------|------|--------|
| **바렐** | 외곽 지지·정렬 | Al, Ti, Invar |
| **스페이서** | 렌즈 간격 유지 | Al, 스틸, 유리 |
| **리테이너 링** | 렌즈 고정·프리로드 | 나사, 스프링 |
| **시트/본드** | 응력 분산, 고정 | Viton, 에폭시 |

### 프리로드(Preload) 설계

| 방식 | 특징 |
|------|------|
| **나사 리테이너** | 단순, 조정 가능 | 
| **스프링 프리로드** | 열팽창 흡수, 안정적 |
| **본드** | 응력 낮음, 영구 |

## 6.3 렌즈 지지·본드 설계 원칙

| 원칙 | 이유 |
|------|------|
| **가장자리 지지** | 광학면 손상·응력 방지 |
| **점/선 접촉** | 면 접촉은 응력 집중 |
| **CTE 매칭** | 온도 변화 편심 방지 |
| **균일 본드** | 비대칭 응력 → 편심 |
| **UV/열 경화 조건 관리** | 수축 응력控制 |

## 6.4 다연 렌즈계 조립 공정 예시

```
[1차 렌즈 세팅] → [스페이서] → [2차 렌즈] → ... → [프리로드] → [간섭계 정렬] → [본드/잠금] → [MTF 검사]
```

| 공정 | 검사 병행 |
|------|----------|
| 렌즈 반입 | 표면·이물 검사 |
| 1차 조립 | 1차 간섭계 |
| 중간 조립 | 편심·간격 확인 |
| 최종 | MTF, 파형 |

## 6.5 열 해석 포인트 (굴절계)

| 항목 | 해석 내용 |
|------|----------|
| **렌즈 간격 변화** | Spacing Δ → 초점 이동 |
| **렌즈 형상 변화** | 곡률·두께 변화 |
| **바arel 변형** | 렌즈 편심 유발 |
| **초점 이동** | Back focus drift |
