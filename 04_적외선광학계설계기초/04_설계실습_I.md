# 4. 적외선 광학계 설계 실습 I

> Day2 오후 · Objective, Multiple-material, Afocal

## 4.1 실습 A: 적외선 Objective Lens 설계

### 요구사항 예시

| 항목 | 값 |
|------|-----|
| 대역 | LWIR 8~14 µm |
| 초점거리 | 50 mm |
| f/# | f/1.0 |
| FOV | ±10° |
| 검출기 | Microbolometer 640×512, 12 µm |

### 설계 절차

```
[Aperture·Wavelength·Field 설정] → [초기 2~3장 구조] → [Ge 선택] → [최적화] → [MTF 평가]
```

| 단계 | Zemax 작업 |
|------|-----------|
| 1 | LWIR 파장 (8, 10, 12, 14 µm) |
| 2 | Aperture: Entrance Pupil 50mm (f/1) |
| 3 | Field: 0, 5, 10° |
| 4 | 초기: Ge 단일 또는 이중 |
| 5 | Merit Function: RMS spot |
| 6 | MTF @ 41.7 lp/mm (Nyquist 12µm) |

## 4.3 실습 C: Afocal System

### Afocal이란

> 입력·출력이 **평행광**인 시스템 (배율만, 초점 없음)

| 응용 | 예 |
|------|-----|
| **빔 익스팬더** | 레이저 |
| **망원경 부속** | 포켓홀 |
| **LiDAR 광학** | 송수신 |

### Zemax 구현 포인트

```
[입사 평행광] → [광학계] → [출사 평행광]
```

| 항목 | 설정 |
|------|------|
| **Field** | 축상 (평행광) |
| **Object** | Infinity |
| **Analysis** | Exit Pupil 위치·크기, Wavefront |
