# 3. 적외선 렌즈 설계 전략 (Code V & Zemax)

> Day2 오전 · IR 설계 특화 전략

## 3.1 적외선 설계 vs 가시광 설계

| 항목 | 가시광 | 적외선 |
|------|--------|--------|
| 소재 | 다수의 유리 | 제한적 (Ge, Si, ZnSe 등) |
| 분산 관리 | 아크로마트 필수 | 재료가 적어 상대적 쉬움 |
| n | 1.5~2.0 | 2~4 (매우 높음) |
| 반사 손실 | 적음 | 커짐 → AR 코팅 필수 |
| 열 | 거의 무시 | 설계 핵심 |
| 검출기 | CMOS/CCD | InSb/MCT/Microbolometer |

## 3.2 소재 선택 전략

### 대역별 추천

| 대역 | 1차 후보 | 대체 |
|------|---------|------|
| **SWIR** | Si, Silica | Chalcogenide |
| **MWIR** | Si, Ge, ZnSe | Chalcogenide |
| **LWIR** | Ge, ZnSe, Chalcogenide | ZnS, GaAs |

### 선택 기준표

| 기준 | 항목 |
|------|------|
| 투과 | 대역 내 투과율 |
| n | 반사 손실, 설계 자유도 |
| dn/dT | 온도 민감도 |
| CTE | 기계적 안정성 |
| 가공성 | 연마·비산 가능성 |
| 비용 | Ge 비쌈, Si 저렴 |
| 비중 | 무게 제약 |

## 3.3 아포칼(A-thermal) 설계

### 목표
```
ΔT 변화 → 초점 이동 Δf ≈ 0
```

### 방법
| 방법 | 내용 |
|------|------|
| **재료 조합** | 서로 다른 dn/dT·CTE로 상쇄 |
| **기계적 보상** | 바arel CTE로 초점 이동 보정 |
| **혼합** | 광학+기계 동시 최적화 |

## 3.4 Code V vs Zemax 실무 비교

| 작업 | Code V | Zemax |
|------|--------|-------|
| **초기 탐색** | 빠른 파라메트릭 | UI直觀 |
| **최적화** | 강력한 Global Synthesis | Hammer, Local |
| **열 해석** | Thermal 환경 설정 | Thermal setting |
| **적외선 검출기** | Detecter 설정 | Same |
| **배치·CAD** | 연계 | 연계 |

## 3.5 적외선 설계 워크플로우

```
[요구사항] → [대역·검출기 확정] → [소재 후보] → [초기 구조] → [최적화]
                                                              ↓
[열·기계 검토] ← [MTF·Distortion 평가] ← [아포칼 보정]
```

## 3.6 실무 팁

- **Ge**는 n이 높아 **1장으로 강한 굴절** 가능하지만, 반사 손실·무게 주의.
- **Chalcogenide**는 몰딩 가능 → 대량생산 유리.
- **dn/dT**가 큰 소재(Ge 등)는 **아포칼이 필수**.
- MWIR/LWIR는 **열 배경·스트레이** 광학 설계 단계에서 차단.
