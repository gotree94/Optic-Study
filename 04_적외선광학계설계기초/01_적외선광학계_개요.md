# 1. 적외선 광학계 개요

> Day1 오전 · IR 대역 이해와 설계 전략

## 1.1 전자파 스펙트럼과 적외선

| 대역 | 파장 | 응용 |
|------|------|------|
| 가시광(Visible) | 0.38~0.78 µm | 카메라 |
| **NIR(근적외)** | 0.78~1 µm | 야간, 통신 |
| **SWIR(단파)** | 1~3 µm | 습도, 결함 |
| **MWIR(중파)** | 3~5 µm | 열화상, 가스 |
| **LWIR(장파)** | 8~14 µm | 상온 열화상 |
| **VLWIR** | 14~30 µm | 연구 |

```
가시광   NIR    SWIR    MWIR      LWIR      VLWIR
|--|-----|------|-------|---------|---------|
 0.4    1      3       5         8        14    (µm)
```

## 1.2 적외선 광학 소재

| 소재 | 투과 대역 | 굴절률(n) | 특징 |
|------|----------|-----------|------|
| **Germanium (Ge)** | MWIR/LWIR | ~4.0 | 높은 n, 무거움, 온도 의존 |
| **Silicon (Si)** | MWIR | ~3.4 | 저렴, MWIR |
| **ZnSe** | MWIR/LWIR | ~2.4 | 광대역, 노란색 |
| **ZnS** | MWIR/LWIR | ~2.2 | 기계적 강성 |
| **Chalcogenide** | MWIR/LWIR | ~2.5~2.8 | 비정질, 몰딩 가능 |
| **Calcium Fluoride** | NIR/SWIR | ~1.4 | 저분산 |

## 1.3 적외선 광학계 설계 특징

| 항목 | 가시광 대비 |
|------|-----------|
| **분산** | 적외선에서 재료 선택↓, 색수차 관리 |
| **굴절률** | Ge 등 매우 높음 → 반사 손실↑ |
| **열 배경** | 광학계 자체 방사 → 냉각·차단 |
| **檢出器** | InSb, HgCdTe, Microbolometer |
| **렌즈 두께** | 두꺼운 렌즈 → 열·무게 이슈 |
| **아포칼 설계** | 온도 변화 대응 필수 |

## 1.4 비냉각 vs 냉각

| 구분 | 냉각(Cooled) | 비냉각(Uncooled) |
|------|-------------|-----------------|
| 검출기 | InSb, MCT | Microbolometer |
| 온도 | ~77K | 상온 |
| 성능 | 높음 | 중간 |
| 비용·크기 | 높음/큼 | 낮음/작음 |
| 응용 | 군사, 위성 | 자동차, 상용 열화상 |

## 1.5 설계 전략 5원칙

1. **소재 선택**: 대역·n·기계·열·비용 종합
2. **아포칼(a-thermal)**: 온도 변화 초점 유지
3. **열 차단**: 광학계 방사·스트레이 경로 관리
4. **검출기 매칭**: 픽셀 피치,冷동 요구
5. **실용성**: 가공·조립·검사 가능성

## 1.6 Code V vs Zemax (개요)

| 항목 | Code V | Zemax (OpticStudio) |
|------|--------|---------------------|
| 강점 | 고급 최적화, 대형계 | UI, 실습, 광범위 사용 |
| 적외선 | 지원 | 지원 |
| 라이선스 | 높음 | 중간 |
| 학습 곡선 | 가파름 | 완만 |
| 응용 | 연구소, 대형 | 산업, 중소 |
