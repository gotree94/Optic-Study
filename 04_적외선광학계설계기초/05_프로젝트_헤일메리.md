# 5. 프로젝트: 헤일메리로 배우는 적외선 광학

> Day3 오전 · 실제 사례("헤일메리" 프로젝트)로 배우는 적외선 광학 통합 이해

## 5.1 "헤일메리(Hail Mary)" 접근법의 의미

> 복잡한 문제를 **단계적·실용적·반복 개선**으로 풀어가는 전략.
> (동명의 SF 소재처럼 "최후의 성공 확률 높은 수"를 좇는 실무 마인드)

| 원칙 | 내용 |
|------|------|
| **간단히 시작** | 완벽보다 동작하는 초안 |
| **리스크 우선** | 큰 불확실성부터 해소 |
| **반복 검증** | 설계→시뮬→프로토타입 사이클 |
| **다학제 통합** | 광학·기계·열·검출기 동시 고려 |

## 5.2 프로젝트 개요 (예시 시나리오)

| 항목 | 내용 |
|------|------|
| **목표** | 비냉각 LWIR 열화상 카메라 광학계 |
| **대역** | 8~14 µm |
| **검출기** | Microbolometer 640×480, 12 µm |
| **제약** | 소형·경량·저비용, -20~+50°C |

## 5.3 단계별 진행

### Step 1: 요구사항 명확화
- FOV, f/#, MTF 목표, 크기·질량·비용

### Step 2: 소재·구조 탐색
- Ge 단일 vs Ge+Chalcogenide 이중
- 몰딩(Chalcogenide) vs 정밀 가공

### Step 3: 초기 설계 (Zemax)
- 2~3장 구조로 최적화
- MTF, Distortion 초기 확인

### Step 4: 열·아포칼 검토
- Thermal setting, dn/dT 반영
- 온도별 초점 이동 확인

### Step 5: 기계·조립 검토
- 바arel, CTE, 프리로드
- 정렬 자구 설계

### Step 6: 검사·평가 계획
- 간섭계, MTF, 열 시험

## 5.4 결정 포인트 테이블

| 결정 | 선택지 | 기준 |
|------|--------|------|
| 렌즈 수 | 1장 vs 2장 vs 3장 | 성능 vs 비용 vs 크기 |
| 소재 | Ge vs Chalcogenide | 비용·가공·온도 |
| 보정 | 광학 아포칼 vs 기계 보정 | 복잡도 vs 성능 |
| 검출기 | 고성능 vs 저비용 | 애플리케이션 |

## 5.5 교훈 정리

| 교훈 | 설명 |
|------|------|
| **열이 왕** | LWIR는 열이 성능 결정 |
| **단순함의 힘** | 적은 렌즈 수로 실용 성능 |
| **통합 사고** | 광학만으로는 끝나지 않음 |
| **데이터 기반** | 시뮬→실측 사이클 |
