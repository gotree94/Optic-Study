# 6. 적외선 광학계 설계 실습 II: LWIR / MWR 비냉각

> Day3 오후 · 비냉각(Uncooled) MWIR·LWIR 광학계 설계 실습

## 6.1 비냉각 광학계 이해

| 항목 | MWIR 비냉각 | LWIR 비냉각 |
|------|-----------|-----------|
| 대역 | 3~5 µm | 8~14 µm |
| 검출기 | InGaAs, PbSe 등 | Microbolometer |
| 대기창 | 중간 | 넓음 |
| 응용 | 가스, 화염 | 상용 열화상, 자동차 |
| 소재 | Si, Ge, ZnSe | Ge, ZnSe, Chalcogenide |
| 열 배경 | 관리 필요 | 매우 중요 |

## 6.2 실습 A: LWIR 비냉각 광학계

| 항목 | 값 |

| 초점거리 | 25 mm |
| f/# | f/1.0 |
| FOV | 30° |
| 검출기 | Microbolometer 640×512, 12 µm |
| 온도 | -20~+50°C |

### 설계 절차

```
[시스템 설정] → [초기 Ge 단일/이중] → [최적화] → [Thermal 설정] → [아포칼] → [MTF 평가]
```

### 체크 포인트

| 항목 | 확인 |
|------|------|

| Distortion | 애플리케이션 기준 |
| 초점 이동 (ΔT) | 허용 범위 |
| 두께·질량 | 실장 제약 |

## 6.3 실습 B: MWR(MWIR) 비냉각 광학계

### LWIR 대비 차이

| 항목 | LWIR | MWIR |
|------|------|------|
| 파장 | 길다 | 짧다 |
| 해상도 | 동일 픽셀에서 낮음 | 높음 |
| 소재 | Ge 중심 | Si, Ge, ZnSe |
| 대기 투과 | 연무에 강함 | 선택적 |
| 열 배경 | 매우 중요 | 중요 |

### 설계 포인트

- **Si**가 MWIR에서 유용 (저렴, dn/dT 관리)
- 색수차가 LWIR보다 상대적 존재 → 재료 배합 고려
- MWR+LWIR **이중대역** 설계 도전 과제
