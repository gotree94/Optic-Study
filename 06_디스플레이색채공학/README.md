# 디스플레이 색채공학 (Display Color Engineering)

> Color의 **정량화 원리**와 **인간 시각 인지**, 국제 표준, 감성 화질, Gamma/HDR까지

## 강의개요

1) Display 화질 성능 중 가장 중요한 특성인 **Color에 대한 정량화 원리**와 **인간의 시각 인지 특성**을 소개하여 감성화질에 대해 올바르게 이해하는 계기를 제공
2) IT기기들의 Color에 대한 **국제 표준**을 소개하여 Device별 색재현 특성의 차이를 설명
3) **OLED를 중심**으로 다양한 감성 화질 신 측정법을 소개하여 물리적 특성법의 한계를 설명
4) **Gamma와 HDR**에 대해 소개하여 Digital 화질의 올바른 설계 방향을 소개
5) 30여 년간 다양한 Display에 대해 연구 개발한 경험을 바탕으로 **Q&A를 통해 Display용 Color Solution 제공**
