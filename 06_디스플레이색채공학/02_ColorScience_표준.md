# 2. Color Science 표준

> 11:00~12:30 · IT기기 Color 국제 표준과 Device별 색재현 차이

## 2.1 왜 표준이 필요한가

| 이유 | 예 |
|------|-----|
| Device별 색 차이 | 모니터·폰·TV·인쇄 색이 다름 |
| 콘텐츠 재현 | 같은 이미지가 다르게 보임 |
| 산업 호환 | 제조사 간 소통 |

## 2.2 대표 Color 표준

| 표준 | 용도 | 특징 |
|------|------|------|
| **sRGB** | PC·웹 표준 | 넓은 호환, 좁은 색역 |
| **Adobe RGB** | 인쇄·포토 | 넓은 녹색역 |
| **DCI-P3** | 영화·디스플레이 | 넓은 색역, 가까운 산업 표준 |
| **Rec.709** | HD 방송 | sRGB와 유사 |
| **Rec.2020** | UHD 방송 | 매우 넓은 색역 |
| **NTSC** | 구 방송 | 참고 기준 |
| **BT.1886** | TV 감마 | 어두운 환경 기준 |

## 2.3 색역(Color Gamut) 비교

```
        y
        │   ●Rec.2020 (가장 넓음)
        │  ● DCI-P3
        │ ●  ●Adobe RGB
        │●    ●sRGB (가장 좁음)
        │ ●      ●
        ┼──────────────→ x
```

| 색역 | 상대적 넓이 | 응용 |
|------|-----------|------|
| sRGB | 기준(좁음) | 웹, 사무 |
| DCI-P3 | ~25%↑ | 스마트폰, 영화 |
| Adobe RGB | 녹색↑ | 인쇄 |
| Rec.2020 | 매우 넓음 | UHD, OLED |

## 2.4 Device별 색재현 특성 차이

| Device | 광원 특성 | 색역 | 과제 |
|--------|----------|------|------|
| **LCD** | 백라이트+필터 | 패널·백광 의존 | 넓은 색역, 편광 |
| **OLED** | 유기 발광체 | 넓은 색역 가능 | 번인, 색 정확도 |
| **LED 조명** | 스펙트럼 좁음 | 제한 | 연색성 |
| **프로젝터** | 광원+DLP/LCD | 중간 | 밝기·색 동시 |
| **인쇄** | 반사 | CMYK | 색역 한계 |

## 2.5 표준화 기관

| 기관 | 표준 예 |
|------|--------|
| **CIE** | 색 체계, 색차 |
| **IEC/ISO** | sRGB, DCI 관련 |
| **SMPTE** | 영상·영화 (DCI-P3, Rec.2020) |
| **VESA** | 디스플레이 성능 |
| **ITU-R** | 방송 (Rec.709/2020) |

## 2.6 색 정확도 평가 지표

| 지표 | 정의 |
|------|------|
| **ΔE (Delta E)** | 두 색의 시각적 차이 ( Lab 또는 u'v') |
| **ΔE 평균·최대** | 전반·worst-case |
| **색역 커버리지** | 표준 대비 % |
| **White Point 오차** | D65 대비 색온도 편차 |

| ΔE 기준 (일반 참고) | 인상 |
|---------------------|------|
| < 1 | 거의 구분 불가 |
| 1~2 | 훈련된 눈에 구분 |
| 2~5 | 일반인 구분 가능 |
| > 5 | 명확한 차이 |

## 2.7 실무 정리

- **sRGB는 호환**, **P3/2020은 품질** — 용도별 선택.
- Device 색차이는 **스펙트럼·색역·보정**의 종합.
- 색 품질은 **ΔE와 색역 커버리지**로 관리.
