# 3. Color Science 응용

> 13:30~14:20 · 감성 화질, OLED 신 측정법, Gamma·HDR

## 3.1 감성 화질(QoE)이란

| 구분 | 내용 |
|------|------|
| **물리적 화질** | ΔE, 색역, 감마 수치 |
| **감성 화질** | 사람이 "좋다/나쁘다"고 느끼는 인상 |
| **차이** | 수치가 같아도 인상이 다를 수 있음 |

```
[물리 측정] → [인간 시각 모델] → [감성 점수]
```

## 3.2 물리적 특성법의 한계

| 한계 | 예 |
|------|-----|
| 평균값 | 부분적 색 번짐 무시 |
| 정적 측정 | 동적 화면·장면 미반영 |
| 표준광원 | 실제 콘텐츠 스펙트럼 다름 |
| 단일 지표 | 복합 인상 단순화 |

## 3.3 OLED 중심 신 측정법

| 기법 | 목적 |
|------|------|
| **스펙트럼 기반 ΔE** | 광원 스펙트럼 반영 정밀 색차 |
| **적응(Adaptation) 모델** | 화이트 밸런스 적응 반영 |
| **콘텐츠 기반 평가** | 실제 영상 장면 분석 |
| **번인·감쇠 모니터링** | 시간에 따른 색 변화 |
| **HDR 색량** | 넓은 휘도·색역 동시 평가 |

## 3.4 Gamma와 화질

### 감마(Gamma)란

```
표시휘도 L ∝ 입력값^γ
```

| 감마 | 인상 |
|------|------|
| γ=1 | 선형 (어두움) |
| γ≈2.2 | sRGB 표준 |
| 높은 γ | 대비 강함 |

### 왜 감마가 중요한가
- 인간 시각은 **어두운 차이에 민감** → 어두운 곳에 비트 할당↑
- 감마 부적합 → **밴딩, 대비 왜곡**

## 3.5 HDR(High Dynamic Range)

| 항목 | SDR | HDR |
|------|-----|-----|
| 휘도 범위 | ~100 nit | 1000~10000 nit |
| 비트 | 8 bit | 10~12 bit |
| 감마/전달 | sRGB/2.2 | PQ(HDR10), HLG |
| 색역 | sRGB | P3~2020 |

### HDR 표준·포맷

| 표준/포맷 | 특징 |
|-----------|------|
| **HDR10** | 10bit, static metadata |
| **Dolby Vision** | 12bit, dynamic metadata |
| **HLG** | 방송 호환 |
| **PQ (SMPTE ST 2084)** | 절대 휘도 기반 |

## 3.6 Digital 화질 설계 방향

| 원칙 | 내용 |
|------|------|
| **스펙트럼 일치** | 광원·센서·표시 정합 |
| **감성 지표 병행** | ΔE + 인상 평가 |
| **HDR·넓은 색역** | P3/2020 + 10bit↑ |
| **보정 파이프라인** | 3D LUT, 적응 모델 |
| **장면 기반 평가** | 정적 수치 넘어 동적 검증 |
