# 1. 색도도(Chromaticity Diagram) 정의

> 10:00~10:50 · Color를 숫자로 정량화하는 체계

## 1.1 색을 정량화해야 하는 이유

| 이유 | 설명 |
|------|------|
| **재현** | 같은 색을 기기 간에 일관되게 표현 |
| **측정** | 객관적 수치로 품질 관리 |
| **표준** | 국제 규격과 소통 |
| **설계** | 디스플레이·광원 설계 언어 |

## 1.2 CIE 1931 색도 시스템

### 3원색 체계

```
RGB 3원색 → CIE XYZ → 색도 x, y
```

| 색공간 | 의미 |
|--------|------|
| **X, Y, Z** | CIE 기준 삼원색 (Y = 휘도) |
| **x, y** | 색도 (x = X/(X+Y+Z), y = Y/(X+Y+Z)) |
| **z** | 1 − x − y (생략 가능) |

## 1.3 색도도(Chromaticity Diagram)

```
        y
    1.0 ┤      ●초록
        │    ●   ●
        │  ●       ●
    0.5 ┤ ●    보라   ●●노랑
        │●  파랑●     ●주황
        │ ●          ●
    0.0 ┼────────●────→ x
        0   0.5   1.0
        
   말발굽 모양 = 가시광 스펙트럼 경계
```

| 요소 | 정의 |
|------|------|
| **보색 경계(외곽선)** | 스펙트럼 색 (순색) |
| **백색 영역** | 중앙부 |
| **색도(x,y)** | 색의 위치 |
| **보색점** | 직선으로 연결되어 백색이 되는 두 색 |

## 1.4 색온도와 Planckian 궤적

| 개념 | 설명 |
|------|------|
| **색온도(K)** | 흑체 방출 색의 온도 |
| **Planckian 궤적** | 흑체가 온도에 따라 지나는 색의 궤적 |
| **CCT(관련 색온도)** | 백색광의 근사 색온도 |
| **D65** | 6500K 대표 백색 기준 |

## 1.5 색의 3요소

| 요소 | 정의 | 측정 예 |
|------|------|--------|
| **휘도(Luminance)** | 밝기 | Y (cd/m², nit) |
| **색도(Chromaticity)** | 색의 종류 | x, y 또는 u', v' |
| **채도(Saturation)** | 색의 순도 | 거리, 비율 |

## 1.6 u'v' (CIE 1976) 균등 색 공간

| 공간 | 장점 |
|------|------|
| **CIE 1931 xy** | 역사적 표준, 널리 사용 |
| **CIE 1976 u'v'** | 시각적 균등성 우수 — 색차 계산에 유리 |

```
ΔE 색차: 두 색의 시각적 차이 (u'v' 또는 Lab 기반)
```

## 1.7 실무 정리

- **x,y**로 색 위치 표시, **Y**로 밝기 표시.
- **색온도·D65**는 백색 기준으로 핵심.
- 색차·비교에는 **u'v' 또는 Lab ΔE** 권장.
