# 1. 빛 (Light)

> 상용렌즈선정 1강 · 오전 10:00~10:30 목표

## 1.1 빛의 이중성

| 성질 | 설명 | 광학계에서의 의미 |
|------|------|------------------|
| **파동성** | 굴절, 간섭, 회절, 편광 | 렌즈 설계·해상도 이론 |
| **입자성(광자)** | 에너지量子, 광전효과 | 센서(CCD/CMOS), 레이저 |

> **한 줄 정리**: 상용렌즈 실무에서는 **파동성(굴절·회절)** 위주로 이해하면 충분.

## 1.2 광원 유형

| 유형 | 예 | 특징 | 렌즈 선택 영향 |
|------|-----|------|---------------|
| 자연광 | 태양 | 광시, 스펙트럼 넓음 | 색수차 고려 |
| 백열전구 | 텅스텐 | 색온도 낮음(~3000K) | IR 차단 필요할 수 있음 |
| 형광등 | 백열 대체 | 스펙트럼 불연속 | Flicker, 색 편차 |
| LED | 다양한 | 좁은 스펙트럼, 효율↑ | 모노/컬러 선택 |
| 레이저 | 반도체, HeNe | 단색·고정밀 | 간섭· speckle 주의 |
| EL / OLED | 디스플레이 | 면광원 | 넓은 시야각 대응 |

## 1.3 스펙트럼과 색온도

```
가시광 스펙트럼 (약 380~780 nm)
┌────────────────────────────────────────────┐
│ 보라  파랑  초록  노랑  주황  빨강          │
└────────────────────────────────────────────┘
```

| 용어 | 정의 | 실무 포인트 |
|------|------|-----------|
| **파장(λ)** | 파동의 길이, nm 단위 | 굴절률 차이로 색수차 발생 |
| **스펙트럼** | 파장별 세기 분포 | 센서-렌즈 매칭 |
| **색온도(K)** | 흑체 방출 기준 색 | 조명-카메라 화이트밸런스 |
| **CRI(연색지수)** | 조명이 사물색을 재현하는 정도 | 머신비전·촬영 |

## 1.4 굴절의 기초 — Snell의 법칙

```
        공기 (n1 ≈ 1.0)
    ─────────────────────
           ↘
             ↘  굴절각 θ2
               ↘
    ─────────────────────
        유리 (n2 ≈ 1.5)
        
   n1·sinθ1 = n2·sinθ2
```

| 용어 | 의미 |
|------|------|
| **굴절률(n)** | 빛이 얼마나 느려지는지 (공기 1.0, 유리 1.5, 다이아몬드 2.4) |
| **전반사** | 밀도 큰 매질→작은 매질, 임계각 이상 |
| **분산(Dispersion)** | 굴절률이 파장에 따라 다름 → 색수차 |

## 1.5 편광

| 상태 | 설명 | 응용 |
|------|------|------|
| 자연광 | 모든 방향 진동 | 일반 조명 |
| 선형 편광 | 한 방향 진동 | LCD, 눈부심 차단 |
| 원형 편광 | 회전 진동 | 3D, 레이저 광학 |

> 상용렌즈 선택 시 **편광 필터·블록** 응용이 필요한 경우(눈부심, 유리 반사) 편광 상태 확인.

## 1.6 정리 — 렌즈 선정에 필요한 "빛" 지식

- [x] 광원 스펙트럼 → **색수차·IR차단** 판단
- [x] 굴절률·분산 → **재료 선택** 근거
- [x] 광원 크기·방향 → **조명 설계** 필수
- [x] 편광 → **눈부심·반사** 문제 해결
