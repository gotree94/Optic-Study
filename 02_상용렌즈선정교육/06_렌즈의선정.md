## 6.2 요구사항 → 사양 매핑표

| 요구사항 | 확인 사항 | 관련 사양 |
|----------|----------|----------|
| 촬영 거리 | Working distance | 최소/최대 초점거리 |
| 대상 크기 | FOV(Field of View) | 초점거리, 센서 크기 |
| 해상도 | 필요한 lp/mm 또는 픽셀 | MTF, 해상도 등급 |
| 조명 환경 | 밝기, 스펙트럼 | f/#, IR filter |
| 정밀 측정 | 배율 변화 허용 | Telecentric 여부 |
| 외형 제약 | 설치 공간 | 길이, 지름, 마운트 |
| 환경 | 온도·분진·진동 | 산업용 등급 |
| 비용·납기 | 양산 | 재고 모델 vs 커스텀 |

## 6.3 FOV와 초점거리 계산 (개념)

```
FOV ≈ (센서 크기) × (거리) / (초점거리)
```

| 고정 변수 | 바꾸는 변수 | 결과 |
|-----------|------------|------|
| 거리 고정 | f ↑ | FOV ↓ (망원) |
| f 고정 | 거리 ↑ | FOV ↑ (넓게) |
| f·거리 고정 | 센서 ↑ | FOV ↑ |

> **역설계**: 대상 크기·거리·센서로부터 필요한 f를 역산 → 카탈로그 후보군 축소.

## 6.4 Telecentric vs 일반 렌즈

| 항목 | 일반 렌즈 | Telecentric |
|------|----------|-------------|
| 배율 변화 | 거리에 따라 변함 | 거의 일정(축나란) |
| 관점 | 원근감 | 오르토그래픽 |
| 비용 | 저렴 | 비쌈 |
| 적용 | 일반 영상 | 치수 측정, 검사 |
| 제약 | — | 대상 > 렌즈 구경 불가 |

## 6.5 카탈로그/_datasheet 체크리스트

| 항목 | 확인 포인트 |
|------|-----------|
| 센서 호환 | 1/1.8", 2/3", 1.1" 등 image circle |
| 해상도 | MPixel 대응 수준 |
| f/# 범위 | 최대 밝기 vs 심도 |
| TV 왜곡 / Distortion | 측정용 시 <0.5% |
| 왜곡 그래프 | 주변부까지 |
| MTF 곡선 | 중앙/주변, lp/mm 대역 |
| BFL / Flange | 마운트 호환 |
| Working distance | 최소 초점 거리 |
| 온도 범위 | -20~+60°C 등 |
| 편광 편차 | LCD 환경 시 |
