# 7. 렌즈 세팅 (Lens Setup)

> 다음 날 오전 · 선택한 렌즈를 실제 시스템에 맞게 정렬·최적화

## 7.1 세팅 절차

```
[마운트 장착] → [초점거리(Focus)] → [조리개(Iris)] → [렌즈 위치 미세조정] → [최종 고정·검증]
```

## 7.2 초점(Focus) 세팅

| 단계 | 방법 | 팁 |
|------|------|-----|
| 1. 거치 | 마운트 고정, 유격 없이 | 나사 풀림 방지 |
| 2. 초침 | 테스트 차트, 중앙/주변 확인 | 피크 MTF 또는 육안 |
| 3. 미세조정 | 초점링 나사 또는 전동 | 방향 확인 후 소량씩 |
| 4. 고정 | 나사 잠금, 본드 | 진동 환경 시 |

### 초점 체크 도구
- **테스트 차트** (Siemens star, 1951 USAF)
- **MTF 계측 소프트웨어**
- **Zebra 패턴** (지마·초점 흔들림 확인)

## 7.3 조리개(Iris) 세팅

| f/# | 밝기 | 심도 | 해상도 |
|-----|------|------|--------|
| 낮음(f/1.4) | 밝음 | 얕음 | 구면수차 심화 |
| 중간(f/4~f/8) | 적당 | 적당 | **보통 최적** |
| 높음(f/16) | 어두움 | 넓음 | 회절로 흐려짐 |

> **실무 경험칙**: 최적 해상도는 **f/4~f/8** 부근에서 자주 나타남.

## 7.4 렌즈-센서 정렬

| 항목 | 확인 | 조정 |
|------|------|------|
| **초점면(Back Focus)** | 센서 표면에 상 맺힘 | shims, 스페이서 |
| **기울기(Tilt)** | 4방향 MTF 균일 | 마운트 스페이서 조정 |
| **탈중심** | 상 중앙 정렬 | X-Y 마운트 |
| **편심(센서-렌즈)** | 컬러/해상도 편차 | 정밀 마운트 |

## 7.5 조명 세팅 (렌즈와 함께)

| 조명 방식 | 특징 | 렌즈 선택 영향 |
|-----------|------|---------------|
| 백색광(전방) | 범용 | IR filter 확인 |
| 링 조명 | 균일, 그림자↓ | 접사 렌즈와 호환 |
| 백라이트 | 실루엣 검사 | Telecentric 적합 |
| 동축 조명 | 반사면 검사 | 비싼 광학계 |
| 편광 조명 | 눈부심 차단 | 편광 필터 필수 |

## 7.6 세팅 검증 체크리스트

- [ ] 4방향(중앙·상·하·좌·우) MTF 균일 확인
- [ ] 조리개별 MTF 비교 → 최적 f/# 결정
- [ ] 화이트 밸런스·노출 최적화
- [ ] 왜곡 그리드 촬영 → 보정 계수 산출
- [ ] 온도·진동 환경에서 재검증 (산업용)
- [ ] 세팅 조건 문서화 (재현성 확보)
