# 2. 렌즈 (Lens)

> 상용렌즈선정 2강 · 렌즈의 종류·특성·사양표 읽기

## 2.1 렌즈란

> 빛을 **굴절**시켜 초점에 모으거나 퍼뜨리는 광학 부품.

```
 [평행광] →      렌즈       →      초점
 ────────→   ╭───────╮   ────────→  ●
              ╰───────╯
              
 볼록렌즈(수렴)                    오목렌즈(발산)
```

## 2.2 렌즈 기본 파라미터

| 파라미터 | 기호 | 의미 | 예시 |
|----------|------|------|------|
| **초점거리** | f | 초점까지 거리 | 25 mm |
| **조리개(f/#)** | f/N | 초점거리/입사동경 | f/2.8 |
| **입사동경** | EFL·EPD | 빛이 들어가는 구경 | 10 mm |
| **배율** | m | 상/원물 크기 | 0.5x, 10x |
| **후초점거리(BFL)** | BFL | 렌즈 뒷면-초점 | 12 mm |
| **총초점거리(TFL)** | — | 광학적 총 길이 | — |
| **NA(수치조리개)** | NA | 해상도 관련 | 0.25 |

## 2.3 렌즈 유형 분류

| 분류 기준 | 유형 | 특징 |
|-----------|------|------|
| 곡률 | 구면 / 비구면 | 비구면은 수차 적음 |
| 재질 | 유리 / 플라스틱 / 실리콘 / Ge | 파장 대역·환경 |
| 기능 | 단초점 / 매크로 / 텔레포토 / 광각 | 화각·배율 |
| 조리개 | 고정 / 가변 | 응용별 |
| 마운트 | C, CS, F, M42, 산업용 등 | 카메라 센서 호환 |

## 2.4 대표 렌즈 구조

| 이름 | 구조 | 특징 | 용도 |
|------|------|------|------|
| **싱글 렌즈** | 1장 | 저렴, 수차 많음 | 교육, 저가 |
| **아크로마트(이중)** | 2장 (이색유리) | 색수차 보정 | 일반 산업 |
| **아플라나트** | 3~4장 | 평면성 우수 | 계측, 마스크 |
| **포토그라피 렌즈** | 다수 | 전체 성능 균형 | 카메라 |
| **비구면 단일** | 1장(비구면) | 소형·저수차 | 머리카락 구경 |
| **Telecentric** | 다수 | 축 나란, 배율 일정 | 측정, 검사 |

## 2.5 상용렌즈 사양표 읽는 법 (표 예시)

| 항목 | 예시 값 | 해석 |
|------|---------|------|
| 초점거리 | 25 mm | 표준~약간 망원 |
| 조리개 | f/1.4~f/16 | 밝기 조절 가능 |
| 센서 호환 | 1/1.8", 2/3" | 내부 광학크기 확인 |
| 마운트 | C-Mount | 산업 카메라 표준 |
| 해상도 | 5 MPixel 대응 | 센서 픽셀 피치와 매칭 |
| 왜곡 | < 0.1% | 측정 애플리케이션 |
| TV 왜곡 | — | 시청용 성능 |

## 2.6 주의할 점

- **해상도(lpm)** 가 센서 픽셀보다 낮으면 MTF 손실.
- **내부망(Back Focal)** 이 짧은 센서와 불일치 → 초점 안 맞음.
- **Telecentric** 아닌 렌즈는 거리에 따라 배율 변화 → 측정 오차.
- 조리개가 **밝기(f/#)뿐 아니라 심도·해상도**에 영향.
