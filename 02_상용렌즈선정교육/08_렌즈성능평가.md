# 8. 렌즈의 성능평가 (Lens Performance Evaluation)

> 다음 날 오후 13:30~18:00 · 상용렌즈를 객관적 지표로 평가

## 8.1 평가 항목 한눈에 보기

| 항목 | 질문 | 방법 |
|------|------|------|
| **해상도** | 선을 얼마나 잘 구분하나 | USAF 차트, MTF |
| **왜곡** | 형태가 정확한가 | 그리드 차트 |
| **색수차** | 색 번짐이 있는가 | 고대비 엣지 |
| **비네팅** | 주변부 광량 손실 | 균일 백색 장면 |
| **플레어/고스트** | 강광원에서 잔상 | 광원 시험 |
| **편광 편차** | LCD 환경 문제 | 편광 테스트 |
| **심도** | 선명 거리 범위 | 포커스 스윕 |

## 8.2 MTF 평가 (핵심)

```
MTF
1.0 ┤●━━━━━━━┓
    │          ┗━━━━━┓
0.5 ┤                 ┗━━━━━━┓
    │                         ┗━━●
0.0 ┼──┬──┬──┬──┬──┬──┬──→ lp/mm
```

| 지표 | 의미 | 용도 |
|------|------|------|
| MTF50 | 대비 50% 지점 | 감각적 선명도 |
| MTF@Nyquist | 센서 한계 주파수 | 시스템 정합 |
| 대칭/비대칭 | 상하좌우 비교 | 정렬 이상 |

## 8.3 왜곡(Distortion) 평가

| 유형 | 형태 | 측정 |
|------|------|------|
| 배럴 | 볼록 | 그리드 곡선 측정 |
| 핀쿠션 | 오목 | 동일 |
| TV Distortion | 방송 표준 | % 환산 |

**보정 워크플로**: 촬영 → 그리드 분석 → 계수 추출 → 카메라/소프트웨어에 적용

## 8.4 색수차(Lateral Color) 평가

| 방법 | 절차 |
|------|------|
| 엣지 기반 | 고대비 사각 엣지 → RGB 분리 오프셋 측정 |
| 스펙트럼 | 단색광별 MTF 비교 |

허용 기준 예시: 픽셀 피치의 0.5~1배 이하 (애플리케이션별)

## 8.5 비네팅·근일 균일도

```
理想的:     실제:
┌────────┐  ┌────────┐
│ 전면 균일│  │ 모서리↓ │
└────────┘  └────────┘
```

| 항목 | 방법 | 기준 |
|------|------|------|
| 광학 비네팅 | 균일 백색 촬영 | 중앙 대비 % |
| 코사인4 법칙 | 이론 예측 | 광학 설계 이해 |
| 픽셀 균일도(Lens Shading) | 센서 데이터 | 보정 가능 여부 |

## 8.6 플레어·고스트 평가

| 시험 | 조건 | 판정 |
