# 9. 현미경 광학계 (Microscope Optical System)

> 다음 날 오후 · 고배율·고해상도 광학계의 이해와 선정

## 9.1 현미경 구조

```
[대상] → [목표렌즈] → [관시(Intermediate Image)] → [아이피스] → [눈/카메라]
          ↑ NA·배율 결정       ↑ 배율 배가              ↑ 10x 등
```

| 구성 | 역할 |
|------|------|
| **목표렌즈(Objective)** | 핵심 광학 — 해상도·배율 결정 |
| **관시 튜브렌즈** | 목표렌즈 상을 확대·보정 |
| **아이피스** | 눈에 맞게 확대 (보통 10x) |
| **조명계** | 밝기·대비·심도 (대사/투과) |

## 9.2 목표렌즈 핵심 사양

| 사양 | 의미 | 예 |
|------|------|-----|
| **배율** | 4x~100x | 10x, 40x, 100x |
| **NA(수치조리개)** | 빛 수집·해상도 | 0.25(10x), 0.65(40x), 1.25(100x) |
| **보정 레벨** | 색수차 보정 | Achromat, Fluorite, Apochromat |
| **작업거리(WD)** | 대상-렌즈 거리 | 긴 WD → 저배율 |
| **커버글라스 두께** | 0.17mm 기준 | 두께 오차 시 상 품질↓ |

### NA와 해상도

```
해상도 ≈ λ / (2·NA)
```

- **NA ↑ → 해상도 ↑, 심도 ↓, 초점 범위 ↓**

## 9.3 목표렌즈 등급 비교

| 등급 | 색수차 보정 | 가격 | 용도 |
|------|------------|------|------|
| **Achromat** | 2색 | 저 | 일반 |
| **Fluorite(반아포)** | 3색 근사 | 중 | 형광, 정밀 |
| **Apochromat** | 3색 정합 | 고 | 연구, 측정 |

## 9.4 조명 방식

| 방식 | 특징 | 응용 |
|------|------|-----|
| **대사(Bright field)** | 밝은 배경 | 일반 |
| **암시장(Dark field)** | 밝은 대상, 어두운 배경 | 입자·미생물 |
| **위상차(Phase contrast)** | 투명 시료 대비↑ | 세포 |
| **DIC** | 3D 질감 | 연구 |
| **형광** | 형광체 발광 | 생물학 |
| **반사(EP)** | 금속·반도체 | 웨이퍼 검사 |

## 9.5 디지털 현미경·카메라 연계

| 항목 | 포인트 |
|------|--------|
| **C-Mount 어댑터** | 튜브 1x, 0.5x 등 |
| **센서 크기 매칭** | 목표렌즈 image circle |
| **해상도 정합** | NA 대비 센서 픽셀 피치 |
| **MTF 계측** | 목표렌즈+튜브+센서 통합 |

## 9.6 선정 체크리스트

- [ ] 필요한 **배율·NA** 정의
- [ ] **보정 등급** (Achromat vs Apo) — 형광·정밀이면 상위 등급
- [ ] **WD** — 대상 두께·스테이지 여유
- [ ] **커버글라스** 두께 호환
- [ ] **조명 방식** — 시료 특성匹配
- [ ] **디지털 연계** — 어댑터·센서·해상도 정합
- [ ] **계측 응용**이면 **캐리어 스테이지·축 정밀도**

## 9.7 정리 — 현미경 광학계 핵심

| 원칙 | 설명 |
|------|------|
| **목표렌즈가 8할** | NA·보정이 성능 결정 |
| **NA-해상도-심도** | 삼각 트레이드오프 |
| **조명이 반쪽** | 같은 목표렌즈도 조명에 따라 인상이 다름 |
| **디지털 통합** | 카메라·어댑터까지 포함해 시스템 평가 |
