# 4. 기타 렌즈 장애 (Other Lens Defects)

> 상용렌즈선정 4강 · 수차 외에 알아야 할 장애·오염·환경 문제

## 4.1 정렬·기계적 장애

| 장애 | 설명 | 증상 |
|------|------|------|
| **탈중심(Decenter)** | 렌즈 중심偏离 | 상 비대칭, 혼장 증가 |
| **기울기(Tilt)** | 렌즈면 기울기 | 상 흐림 방향성 |
| **면 오염/흠집** | 먼지·스크래치 | 고스트, 플레어,局部 해상도↓ |
| **본드·구조물 번짐** | 조립 부품 반사 | 이미지 내 잔상 |

## 4.2 광학적 장애

| 장애 | 원인 | 결과 |
|------|------|------|
| **플레어** | 강광원이 렌즈면 반사·산란 | 전체 대비↓, 안개현상 |
| **고스트** | 다중 반사 상이 이미지에 겹침 | 점/환상 잔상 |
| **스트레이 라이트** | 비축상 광선 | 이미지 전체 veil |
| **편광 편차** | 렌즈 응력, 코팅 | LCD·3D 촬영 문제 |
| **비네팅(Vignetting)** | 주변부 광량 손실 | 모서리 어두워짐 |

### 플레어·고스트 개요도

```
강광원 → 렌즈면1 반사 → 렌즈면2 반사 → 센서에 잔상(고스트)
                ↓
          대비 감소(플레어)
```

## 4.3 환경·재질 관련 장애

| 장애 | 조건 | 대응 |
|------|------|------|
| **열수차** | 온도 변화 | 무중력·저팽창 소재, 환경 시험 |
| **UV 손상** | 장시간 자외선 | UV 차단 코팅/필터 |
| **습기·결로** | 온도차 | 방습 설계, 질소 충전 |
| **코팅 박리** | 고온·다습 | 코팅 사양 확인 |
| **화학 부식** | 세척제·환경 | 세척 지침 준수 |

## 4.4 센서-렌즈 호환 장애

| 문제 | 원인 | 대응 |
|------|------|------|
| **IR 잔상** | IR-cut 미부재/과다 | IR filter 정합 |
| **컬러 편차** | 스펙트럼 불일치 | 광원·렌즈·센서 통합 |
| **해상도 부족** | lpm < 센서 요구 | 고해상도 렌즈 |
| **후초점 부족** | BFL 부족 | shims, 마운트 조정 |
| **크기 비호환** | 센서 사이즈 > 렌즈 image circle | 흑점·왜곡 심화 |

## 4.5 세척·관리 장애

| 상황 | 증상 | 올바른 대응 |
|------|------|-----------|
| 지문·유분 |局部 흐림, 플레어 | 전용 클리너, 에어 블로어 |
| 물때 | 전체 산란 | 전용 용액, 부드러운 천 |
| 긁힘 | 영구 손상 | 교체, 사전 보호 |
| 청소 도구 오용 | 코팅 손상 | 전용 도구 사용 |

## 4.6 장애 진단 표 (Symptom → 원인)

| 증상 | 가능성 높은 원인 |
|------|----------------|
| 전체 대비 낮음 | 플레어, 오염, 저품질 코팅 |
| 모서리 어두움 | 비네팅, 조리개 너무 열림 |
| 색 테두리 | 색수차, IR filter 문제 |
| 한쪽만 흐림 | 탈중심, 기울기 |
| 원형 고스트 | 강광원, 다중 반사 |
| 왜곡 심함 | 저가 광각, 소프트 미보정 |
