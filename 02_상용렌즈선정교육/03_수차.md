# 3. 수차 (Aberration)

> 상용렌즈선정 3강 · "왜 이미지가 흐려지고 왜곡되는가"

## 3.1 수차란

> 렌즈가 **이상적인 점**을 만들지 못하는 결함 전체.

| 이상 | 실제 |
|------|------|
| 점 → 깨끗한 점 | 점 → 번진 점, 색테두리, 왜곡 |

## 3.2 주요 수차 표

| 수차 | 증상 그림 | 원인 | 대표 해결법 |
|------|----------|------|-----------|
| **구면수차** | 경계 흐림 | 구면 렌즈 | 비구면, 렌즈 배합 |
| **혼장수차** | 상 깨짐(나방) | 주변 광선 | 대칭 설계 |
| **난시** | 가로/세로 분리 | 기울어진 광선 | 조리개 위치, 설계 |
| **포면수차** | 상 휘어짐 | 렌즈 배열 | 분산·배열 조정 |
| **지마(왜곡)** | 통/베개 모양 | 주변 시야 | 소프트 보정, 설계 |
| **축상 색수차** | 색 테두리 | 분산 | 이중초점(Achromat) |
| **횡색수차** | 주변부 색 번짐 | 분산 | 렌즈 배합 |

## 3.3 수차별 상세

### 3.3.1 구면수차
```
 축상 광선 초점:      주변 광선 초점:
      │                  │
      ●  ← 더 가까이       ●  ← 더 멀리
```
- 조리개를 **조이면(f/#↑)** 완화, 밝기 손실.

### 3.3.2 혼장·난시
- 주변 시야에서 상이 풀어짐 → **광각 렌즈**에서 심화.
- Telecentric 렌즈 선택 시 완화.

### 3.3.3 색수차
```
 보라(λ↓):  ────●   (먼 곳 초점)
 빨강(λ↑):  ──●     (가까운 곳 초점)
```
- **아크로마트**: 2색 정합 → 일반용
- **아포크로마트**: 3색 정합 → 고성능

### 3.3.4 지마(Distortion)
| 유형 | 모양 | 예 |
|------|------|-----|
| 배럴(Barrel) | 부풀어 오름 | 광각 |
| 핀쿠션(Pincushion) | 오목하게 | 망원 |

- **보정 가능**: 캘리브레이션·소프트웨어 → 머션비전·로봇비전에 필수.

## 3.4 조리개(f/#)와 수차·심도 관계

| f/# | 밝기 | 심도 | 구면수차 | 해상도(회절) |
|-----|------|------|---------|------------|
| f/1.4 | 밝음 | 얕음 | 심함 | 회절 한계↑ |
| f/4 | 중간 | 중간 | 완화 | 최적 대역 |
| f/11 | 어두움 | 넓음 | 적음 | 회절로 흐려짐 |

## 3.5 상용렌즈 선정 시 수차 체크리스트

- [ ] 용도별 **허용 왜곡율** 확인 (측정용 <0.1%, 영상용 1~3%)
- [ ] 색수차 민감 응용 → **Achromat 이상** 선택
- [ ] 광각·저가 렌즈 → **지마·혼장** 예상, 소프트 보정 계획
- [ ] 밝기(f/#) vs 심도/해상도 **트레이드오프** 이해
- [ ] 제조사 **MTF 곡선** 실물 확인 (특히 주변부)
