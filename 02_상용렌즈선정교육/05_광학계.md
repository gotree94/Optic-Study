# 5. 광학계 (Optical System)

> 상용렌즈선정 5강 · 렌즈가 "모여" 시스템이 되는 방식

## 5.1 광학계란

> 하나 이상의 광학 부품(렌즈, 거울, 프리즘, 필터 등)이 **조합되어 원하는 상을 만드는 체계**.

```
[광원] → [조명계] → [대상] → [렌즈계] → [센서/화면]
```

## 5.2 광학계 구성 요소

| 구성 | 역할 | 예 |
|------|------|-----|
| **수집 광학계** | 대상광 모으기 | 오브젝트 렌즈 |
| **이미징 광학계** | 상 맺기 | 텔레포토, 광각 |
| **조명계** | 대상 균일 조명 | LED, 링, 백라이트 |
| **필터** | 파장·편광 제어 | IR-cut, ND, PL |
| **프리즘/거울** | 경로 변경 | 바이오미러, 굴절계 |
| **센서** | 광전 변환 | CMOS, CCD, InGaAs |

## 5.3 광학계 유형 분류

| 유형 | 특징 | 응용 |
|------|------|------|
| **이미징** | 실제 상 맺힘 | 카메라, 검사 |
| **아포컬(afocal)** | 평행광 입출력 | 망원경, 스코프 |
| **프로젝션** | 대상 확대 상 맺힘 | 영사기, 마스크 |
| **일루미네이션** | 조명만 | 백라이트, 스캐너 |
| **텔레메트리** | 거리 측정 | 레이저 거리계 |

## 5.4 상용 광학계 모듈 예시

| 모듈 | 특징 | 선정 포인트 |
|------|------|-----------|
| **CCTV 렌즈** | 저렴, 호환성 | 센서 크기, 해상도 |
| **기계비전 렌즈** | 견고, 정밀 | 해상도, 왜곡 |
| **Telecentric** | 배율 일정 | 측정 정밀도 |
| **아이리스/줌** | 가변 | 화각·밝기 조절 |
| **접사(매크로)** | 근접 초점 | 최소 초점거리 |
| **현미경 목표렌즈** | 고배율 | NA, 보정 레벨 |

## 5.5 광학계 성능 지표

| 지표 | 정의 | 사용처 |
|------|------|--------|
| **MTF** | 대비 전달 | 전체 성능 |
| **해상도(lp/mm)** | 선 갈라보기 한계 | 카메라 |
| **왜곡(Distortion)** | 기하학적 오차 | 측정 |
| **심도(DOF)** | 선명 거리 범위 | 검사 |
| **광량(Etendue)** | 광선 용량 | 조명·효율 |
| **Eye-box** | 눈 가시 범위 | AR/VR, 망원 |

## 5.6 시스템 통합 체크리스트

- [ ] 광원-렌즈-센서 **스펙트럼 정합**
- [ ] 센서 크기와 렌즈 **이미지 원(circle) 정합**
- [ ] 조명 균일도·방향 **대상 특성 맞춤**
- [ ] 기계적 **마운트·초점 트래블** 확보
- [ ] 환경(온도·진동·분진) **내성 확인**
- [ ] **캘리브레이션 절차** 사전 정의
