# 6. 광산란(미광) 분석기법 및 실습

> Day2 · Stray Light / Ghost 분석과 LightTools 활용

## 6.1 광산란·미광이란

| 용어 | 정의 |
|------|------|
| **Stray Light (미광)** | 의도치 않게 이미지면에 도달하는 빛 |
| **Ghost** | 광학면 간 다중 반사로 인한 잔상 |
| **Flare** | 전체 대비 감소를 유발하는 산란광 |

```
[정상 광로] + [비정상 광로(반사·산란)] → [이미지 대비 감소, 고스트]
```

## 6.2 미광 발생 경로

| 경로 | 원인 | 결과 |
|------|------|------|
| **렌즈면 다중반사** | AR 미흡 | 고스트 |
| **렌즈 가장자리** | 산란 | veil |
| **바arel 내부 반사** | 블랙 코팅 부족 | 전체 haze |
| **디텍터-렌즈** | 센서 반사 | 고스트 |
| **외부 광원** | 시야 밖 강광 | flare |

## 6.3 LightTools 미광 분석 기법

| 기법 | 설명 |
|------|------|
| **광선 추적 + 경로 태깅** | 정상/비정상 경로 분리 |
| **BSDF 모델** | 표면 산란 특성 입력 |
| **Stray Light Analysis** | 의도치 않은 경로 추적 |
| **Ghost 분석** | 면 쌍별 다중 반사 추적 |

### 분석 절차

```
[모델 정밀화 (블랙 코팅, 가장자리)] → [다중 반사 추적] → [미광 맵] → [대비 영향 평가]
```

## 6.4 평가 지표

| 지표 | 의미 |
|------|------|
| ** veiling glare index (VGI)** | 전체 미광 정도 |
| **Ghost intensity** | 고스트 밝기 |
| **스트레이 맵** | 위치별 미광 분포 |

## 6.5 실습: 고스트 분석

| 단계 | 작업 |
|------|------|
| 1 | 렌즈계 모델에 AR 코팅·블랙 바arel 설정 |
| 2 | 강광원(시야 내/외) 배치 |
| 3 | 광선 수 대량 추적 |
| 4 | 이미지면 미광 맵 생성 |
| 5 | 고스트 원인 면 조합 확인 |
| 6 | 개선안 (AR, 블랙, 릿지, 쉐이드) 적용 후 재분석 |

## 6.6 미광 저감 설계 기법

| 기법 | 내용 |
|------|------|
| **AR 코팅** | 반사율↓ |
| **블랙 코팅·립(Ridge)** | 내부 산란↓ |
| **Lens Hood** | 시야 밖 광원 차단 |
| **설계** | 면 배치로 고스트 위치 이동 |
| **디텍터** | AR, 내부 구조 |
