# 4. 최적화 모듈 기본: 간단한 렌즈 조명 설계 실습

> Day1 오후 · LightTools Optimization 모듈 입문

## 4.1 최적화 모듈 개요

| 개념 | 설명 |
|------|------|
| **목표 함수** | 균일도, 효율, 휘도 분포 등 |
| **변수(Variables)** | 렌즈 곡률, 두께, 거리, 위치 |
| **제약(Constraints)** | 최소 두께, 최대 길이, f/# |
| **알고리즘** | Local, Global 등 |

```
[초기 모델] → [변수·목표 설정] → [Optimization Run] → [결과 검토] → [재조정]
```

## 4.2 간단한 렌즈 조명 실습

### 문제 정의

| 항목 | 내용 |
|------|------|
| **광원** | LED |
| **광학계** | 단일/이중 렌즈 |
| **목표** | 대상면 균일 조명, 효율↑ |
| **변수** | 렌즈 곡률, 두께, 광원-렌즈 거리 |

### 실습 절차

| 단계 | 작업 |
|------|------|
| 1 | 광원·렌즈·디텍터 초기 배치 |
| 2 | 렌즈 파라미터 변수 지정 |
| 3 | 균일도·효율 메리트 함수 구성 |
| 4 | Local Optimization 실행 |
| 5 | 결과: 균일도 맵·효율 비교 |
| 6 | 필요 시 변수·제약 조정 반복 |

## 4.3 메리트 함수 예시

| Operand | 목적 |
|---------|------|
| Uniformity | 균일도 목표 |
| Flux Efficiency | 광효율 목표 |
| Size | 전체 길이 제약 |
| Edge Thickness | 렌즈 제작성 |

## 4.4 해석 팁

| 상황 | 점검 |
|------|------|
| 수렴 안 됨 | 변수 범위, 메리트 균형 |
| 균일도↑ 효율↓ | Operand 가중치 조정 |
| 비현실적 결과 | 제약 추가 (두께, 거리) |
| 노이즈↑ | 광선 수 증가 |
