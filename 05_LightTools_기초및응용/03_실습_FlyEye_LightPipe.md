# 3. 조명 설계 실습: Fly Eye Lens / Light Pipe

> Day1 오전 · 대표 조명 광학 구조 실습

## 3.1 Fly Eye Lens 방식

### 구조

```
[광원] → [Fly Eye Lens(마이크로렌즈 어레이)] → [整合] → [대상면(디스플레이 등)]
```

| 구성 | 역할 |
|------|------|
| **Fly Eye Lens** | 광선을 다수의 작은 빔으로 분할 |
| **Integrator** | 빔을 재조합해 균일 조명 |
| **Collimator** | 평행광화 |

### 장점·단점

| 장점 | 단점 |
|------|------|
| 높은 균일도 | 복잡한 설계 |
| 광원 위치 변화 둔감 | 비용↑ |
| 디스플레이·프로젝션에 적합 | 정렬 정밀도 |

### LightTools 실습 절차

| 단계 | 작업 |
|------|------|
| 1 | 광원(램프/LED) 정의 |
| 2 | Fly Eye Lens 어레이 모델링 (마이크로렌즈 패턴) |
| 3 | 후속 콜리메이터·프리즘 배치 |
| 4 | 디텍터를 대상면에 배치 |
| 5 | 광선추적 → 균일도 맵 확인 |
| 6 | 어레이 피치·렌즈 곡률 파라미터화 |

### 평가 지표

| 지표 | 목표 |
|------|------|
| **균일도(Uniformity)** | ±5% 이내 등 |
| **광효율** | 손실 최소 |
| **크기** | 패키지 제약 |

## 3.2 Light Pipe (광학 파이프) 방식 (옵션)

### 구조

```
[광원] → [Light Pipe(광학 막대/도관)] → [출구 면 균일 조명]
```

### 원리

| 원리 | 설명 |
|------|------|
| **전반사(TIR)** | 파이프 내부에서 빛 반복 반사 |
| **혼합(Mixing)** | 여러 반사로 균일화 |
| **축소·확대** | 출구 면적에 따른 밝기 변화 |

### LightTools 실습 절차

| 단계 | 작업 |
|------|------|
| 1 | 광원 생성 (LED) |
| 2 | Light Pipe 형상 모델링 (원기둥, 프리즘) |
| 3 | 내부 표면: 완전 반사 (TIR) |
| 4 | 출구에 디텍터 배치 |
| 5 | 추적 → 출구 균일도·효율 평가 |
| 6 | 길이·단면 최적화 |

### Fly Eye vs Light Pipe 비교

| 항목 | Fly Eye | Light Pipe |
|------|---------|-----------|
| 균일도 | 매우 높음 | 높음 |
| 길이 | 짧게 가능 | 길이 필요 |
| 비용·복잡도 | 높음 | 상대적 저렴 |
| 응용 | 프로젝터, 디스플레이 | 자동차, 소형 기기 |
