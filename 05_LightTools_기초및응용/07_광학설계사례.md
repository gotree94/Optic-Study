# 7. 다양한 광학설계 사례

> Day2 · LightTools로 풀 수 있는 대표 응용 사례

## 7.1 사례 분류

| 분야 | 대표 사례 |
|------|----------|
| **디스플레이** | 백라이트, 라이트 가이드, 프리즘 시트 |
| **자동차** | 헤드램프, 테일램프, 실내 조명 |
| **조명** | 실외등, 다운라이트, 스포트 |
| **센서·LiDAR** | 광원 정렬, 수광 광학 |
| **의료** | 내시경, 광전 검사 |
| **통신·광** | 파이버 정광, 광스위치 |

## 7.2 사례: 디스플레이 백라이트 (BLU)

| 항목 | 내용 |
|------|------|
| **구조** | LED 광원 → 광도판·Prism Sheet → 디스플레이 |
| **목표** | 균일도, 두께↓, 효율↑ |
| **LightTools** | 광선추적, 시트 층 스택업 |

## 7.3 사례: 자동차 헤드램프

| 항목 | 내용 |
|------|------|
| **구조** | 광원 → 반사면·프리즘 → 커버 |
| **목표** | 커팅선(Cutoff), 균일, 법규 |
| **LightTools** | 휘도 분포, 커팅선 분석 |

## 7.4 사례: 센서·LiDAR 광학

| 항목 | 내용 |
|------|------|
| **구조** | 레이저 광원 → 콜리메이터 → 대상 → 수광 렌즈 |
| **목표** | 빔 형상, 수광 효율 |
| **LightTools** | 송수신 정렬, FOV 분석 |

## 7.5 사례: 광전 검사·의료

| 항목 | 내용 |
|------|------|
| **구조** | 광원 → 광섬유·렌즈 → 시료 → 검출기 |
| **목표** | 균일 조명, SNR↑ |
| **LightTools** | 조명 균일, 잡광 제거 |

## 7.6 사례 공통 워크플로우

```
[요구 정의] → [광원 모델] → [광학계 구성] → [시뮬] → [미광·최적화] → [실물 검증]
```

| 단계 | LightTools 활용 |
|------|----------------|
| 요구 정의 | 목표 맵·지표 설정 |
| 광원 모델 | 측정 데이터, LED 파일 |
| 구성 | 3D 모델링 |
| 시뮬 | 광선추적 |
| 미광·최적화 | Stray, Optimization |
| 검증 | 결과 vs 실측 비교 |

## 7.7 정리 — LightTools 실무 활용 가이드

| 상황 | 활용 모듈 |
|------|----------|
| 초기 아이디어 | 광선다이어그램, 균일도 |
| 정밀 조명 | 최적화, 코팅·BSDF |
| 품질 문제 | 미광·고스트 |
| 양산 검증 | 파라미터 스윕, 민감도 |
