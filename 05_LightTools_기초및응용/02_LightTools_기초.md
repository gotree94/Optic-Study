# 2. 조명 광학 설계를 위한 LightTools 기초

> Day1 오전 · 광원/재질/코팅 기본설정 및 시뮬레이션 사용법 (초심자 기준)

## 2.1 LightTools 개요

| 항목 | 내용 |
|------|------|
| **개발** | Synopsys (구 Optical Research Associates) |
| **용도** | 비축상 광학, 조명, 디스플레이, 자동차, 광원 모델링 |
| **방식** | 광선추적(ray tracing) + Monte Carlo |
| **강점** | 복잡한 광원·표면 모델링, 최적화 |

## 2.2 기본 인터페이스

| 창/모듈 | 역할 |
|---------|------|
| **3D 모델링** | 광원·렌즈·표면 배치 |
| **광원 정의** | LED, 백열, 레이저 등 |
| **표면 속성** | 흡수, 산란, 반사, 투과 |
| **분석** | 조도 맵, 휘도, 광선 다이어그램 |
| **최적화** | Optimization 모듈 |

## 2.3 광원 설정

| 광원 유형 | LightTools 예 |
|----------|--------------|
| **Point** | 점광원 |
| **LED** | 디렉토리 데이터, 패턴, 스펙트럼 |
| **Extended** | 면광원 |
| **Ray file** | 측정 광선 파일 |
| **Laser** | 레이저 광원 |

### LED 설정 포인트
- **Photometric** (cd, lm) vs **Radiometric** (W)
- **스펙트럼** 파일 연결
- **지향성** (발광 패턴)

## 2.4 재질(Material)·표면(Surface) 설정

| 속성 | 옵션 예 | 응용 |
|------|--------|------|
| **Absorbing** | 흡수 | 셰이드 |
| **Specular** | 반사/투과 (거울, 유리) | 렌즈 |
| **Lambertian** | 완전 산란 | 디퓨저 |
| **Gaussian** | 반향성 산란 | 실제 표면 |
| **BSDF** | 측정 데이터 | 정밀 모델링 |

## 2.5 코팅(Coating) 설정

| 코팅 | 특성 | 예 |
|------|------|-----|
| **AR (Anti-Reflective)** | 반사↓ | 렌즈 |
| **HR (High-Reflective)** | 반사↑ | 거울 |
| ** Dichroic** | 파장 선택 | 필터 |
| **Enhanced Aluminum** | 광대역 반사 | 거울 |

> **초심자 팁**: 코팅은 **반사율/투과율 곡선**을 표로 입력하거나 기본 코팅 선택.

## 2.6 시뮬레이션 사용법 (기본)

### 광선추적 절차

```
[모델 완성] → [광선 수 설정] → [Run Trace] → [Analysis]
```

| 단계 | 작업 |
|------|------|
| 1 | 광원·표면·디텍터 배치 |
| 2 | 광선 수(Ray count) 설정 (정확도 vs 속도) |
| 3 | Trace 실행 |
| 4 | 조도/휘도 맵, 광선 다이어그램 확인 |

### 광선 수 vs 정확도

| 광선 수 | 정확도 | 속도 |
|---------|--------|------|
| 적음 | 낮음, 노이즈 | 빠름 |
| 많음 | 높음 | 느림 |

> 처음은 **적은 광선으로 테스트**, 최종은 **많은 광선으로 검증**.
