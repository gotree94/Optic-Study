# 5. 최적화 모듈 응용: 렌즈 역설계

> Day1 오후 · 목표 성능으로부터 광학계를 역으로 도출

## 5.1 역설계(Reverse Design)란

> 원하는 **출력(조도 맵, 휘도 분포)** 으로부터 **광학계(렌즈 형상)** 를 역산하는 설계.

```
[목표 분포] → [최적화] → [렌즈 형상 도출] → [검증]
```

## 5.2 역설계 워크플로우

| 단계 | 작업 |
|------|------|
| 1 | 목표 조도·휘도 맵 정의 |
| 2 | 초기 렌즈 구조 추정 |
| 3 | 렌즈 곡률·두께·간격 변수화 |
| 4 | 메리트 함수: 목표 맵과의 차이 최소화 |
| 5 | Global/Hammer 최적화 |
| 6 | 제작성 검토 후 최종 |

## 5.3 실습: LED 컬리메이터 역설계

### 요구사항

| 항목 | 값 |
|------|-----|
| 광원 | LED (Lambertian) |
| 목표 | 평행광, 원형 빔 |
| 조건 | 최대 효율, 최소 길이 |

### 절차

| 단계 | LightTools 작업 |
|------|----------------|
| 1 | LED 광원 정의 |
| 2 | Aspheric 렌즈 초기값 |
| 3 | 렌즈 변수 지정 |
| 4 | 목표: 출사 광선 발산각 최소, flux 최대 |
| 5 | 최적화 → 비구면 계수 도출 |
| 6 | MTF/휘도 맵 검증 |

## 5.4 응용 사례

| 응용 | 목표 | 산출 |
|------|------|------|
| **헤드램프** | 도로 균일 조명 | 반사면 형상 |
| **백라이트** | 디스플레이 균일 | 광도판·렌즈 |
| **포인터** | 초점 빔 | 콜리메이터 |
| **센서 조명** | 대상 균일 | 링·바 렌즈 |

## 5.5 역설계 시 주의점

| 주의 | 이유 |
|------|------|
| **제작 가능성** | 최적화 결과가 너무 극단적일 수 있음 |
| **글로벌 vs 로컬** | 로컬 최적에 빠지지 않도록 Global 병행 |
| **광선 수** | 역설계는 광선 수 충분해야 안정 |
| **실제 광원** | 이상 광원 아닌 측정 데이터 사용 |
