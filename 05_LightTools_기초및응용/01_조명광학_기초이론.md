# 1. 조명 광학 설계를 위한 기초이론

> Day1 오전 · 조명 기초이론 / 단위 / 초기값 계산

## 1.1 조명 광학이란

> 빛을 **원하는 위치·세기·분포**로 보내기 위한 광학 설계.

| 분류 | 예 |
|------|-----|
| **일루미네이션** | 디스플레이 백라이트, 자동차 헤드램프 |
| **프로젝션** | 영사기 광학계 |
| **광통신·센서** | 광원-파이버 정렬 |
| **건축·조명** | 실내 조명 |

## 1.2 조명 기본 단위

| 단위 | 정의 | 기호 |
|------|------|------|
| **광도(Luminous intensity)** | 방향당 빛의 세기 | cd (칸델라) |
| **광속(Luminous flux)** | 전체 빛의 양 | lm (루멘) |
| **휘도(Luminance)** | 면적·방향당 밝기 | cd/m² ( nit) |
| **조도(Illuminance)** | 면적당 떨어지는 빛 | lx (럭스) |
| **방사속(Radiant flux)** | 물리적 광선 | W |
| **발광효율** | W → lm 변환 | lm/W |

```
[광원] → 광속 lm → [광학계] → 광도 cd 방향별 → [대상면] → 조도 lx
```

## 1.3 에틴두(Etendue)

| 항목 | 내용 |
|------|------|
| **정의** | 광원의 면적 × 고체각 (광선 용량) |
| **의미** | 광학계가 전달할 수 있는 최대 광선 양 |
| **불변성** | 이상적 광학계에서 보존 (감소할 수는 있음) |

```
Etendue = A · Ω  (면적 × 고체각)
```

> **핵심**: 광원이 크고 넓으면 렌즈를 아무리 해도 **밝기를 더 높일 수 없음**.

## 1.4 코사인 법칙

| 법칙 | 식(개념) | 의미 |
|------|---------|------|
| **Lambert** | I(θ) = I₀·cosθ | 이상적인 확산 면광원 |
| **조도 법칙** | E = I·cosθ / d² | 거리 제곱 법칙 |

```
      이상적 확산면           실제 LED (지향성)
      ──●──                   ──▲──
     ↙  ●  ↘                 ↙ ▲ ↘
```

## 1.5 초기값 계산 (Concept)

### 예시: LED 조명 설계 초기값

| 단계 | 계산 |
|------|------|
| 1 | 필요 조도(lx)·면적(m²) → 필요 광속(lm) |
| 2 | LED 광도(cd)·빔각 → 후보 선정 |
| 3 | Etendue로 렌즈 구경·FOV 제약 파악 |
| 4 | 코사인 법칙으로 거리·배치 검토 |
| 5 | 효율(광학계 손실) 반영 → 최종 광원 요구 |
