# 9. Summary: 각 수차의 대응방법

> 2일차 5강 · 교육 종합 정리 및 실무 시트

## 9.1 수차별 대응 총정리 표

| 수차 | 증상 | 1차 대응 | 2차 대응 | 시스템 대응 |
|------|------|---------|---------|-----------|
| **구면** | 경계 흐림 | f/# 관리 | 비구면, 장↑ | 소프트 |
| **혼장** | 상 깨짐 | Stop·대칭 | 주변부 최적화 | FOV 제한 |
| **난시** | 방위별 분리 | Stop 위치 | 비축상 제거 | — |
| **포면** | 상 휘어짐 | 분산·간격 | 배열 최적화 | 플랫 필드 |
| **혼성** | 주변부 혼 | 대칭성 | Stop | — |
| **지마** | 왜곡 | Stop | 설계 | 소프트 보정 |
| **축상 색** | 색 테두리 | 이중초점 | Glass | IR filter |
| **횡색** | 주변 색번짐 | 배합 | 시야 | 소프트 |

## 9.2 빠른 진단 시트

| 증상 | 우선 점검 |
|------|----------|
| 전체 흐림 | 구면, 초점, f/# |
| 주변부만 흐림 | 혼장, 난시, Stop |
| 색 테두리 | 축상 색수차, Glass |
| 주변부 색번짐 | 횡색수차 |
| 형태 왜곡 | 지마, Stop |
| 상 휘어짐 | 포면, 간격 |

## 9.3 설계 프로세스 요약

```
요구사항 → 초기구조 → 3차 수차 분해 → 주도 수차 보정 → 최적화
     → MTF·MTF 주변부 평가 → 공차·제작성 → 검증
```
