# 렌즈계 실무기초 및 렌즈설계 접근법

> 광학계 기본 이해 → 렌즈 기능·구성 → **효율적 렌즈설계 접근법** 정립

## 교육대상
- 광학분야에 종사하는 인력
- 장비분야에서 사양·기능분석을 통한 **성능 최적화 도출**이 필요한 분
- **렌즈설계를 통한 사양 변경 및 신규 광학계 개발**이 필요한 인력

## 교육목표
- 광학계 기본을 이해하고 **렌즈계의 기능 및 구성**을 학습
- 렌즈설계 접근·입문을 위해서 **무엇이 필요한지 정리**하여 스스로 설계진행 프로세스를 확립하고 설계를 진행하는 데 도움
