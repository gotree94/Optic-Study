# 6. 수차표시에 대한 설계적 정의

> 2일차 2강 · 수차 지표를 설계 언어로 번역

## 6.1 왜 "설계적 정의"인가

| 측정/표시 | 설계 언어 |
|-----------|----------|
| Spot Diagram이 커짐 | 구면수차 또는 혼장 증가 |
| 초점별 흐림 | 색수차 |
| 상 휘어짐 | 포면수차 |
| 주변부 혼장 | 혼장/난시 |

## 6.2 수차 표시와 설계 의미

| 표시(분석) | 설계적 해석 | 주요 레버 |
|-----------|-----------|----------|
| **Spot Diagram** | 종합 점 상 오차 | 모든 수차 |
| **Wavefront** | 파면 오차 | 정밀 성능 |
| **MTF** | 대비 전달 | 시스템 평가 |
| **Lateral Color** | 횡색수차 | Glass 배합 |
| **Longitudinal Color** | 축상 색수차 | 배합, 재료 |
| **Distortion map** | 왜곡 | Stop, 시야 |
| **Field Curvature** | 포면+난시 | 렌즈 배치 |
| **Coma vs Field** | 혼장 진행 | 대칭성 |

## 6.3 수차-파라미터 관계 맵

| 수차 | 주로 영향받는 파라미터 |
|------|---------------------|
| **구면수차** | 전면 곡률, f/#, 비구면 계수 |
| **혼장** | Stop 위치, 대칭성, 시야 |
| **난시** | Stop, 비축상 배치 |
| **포면** | 분산, 렌즈 간격 |
| **색수차** | Glass ΔV, 간격 |
| **지마** | Stop 위치, 시야각 |

## 6.4 설계적 사고 예시

| 증상 | 의심 | 점검 |
|------|------|------|
| 주변부 MTF 급락 | 혼장/난시 | Stop·대칭성 |
| 경계부 색테두리 | 축상 색수차 | Glass 배합 |
| 전반적 흐림 | 구면수차 | f/#, 비구면 |
| 통/베개 왜곡 | 지마 | Stop 위치 |

## 6.5 정리

- 수차 표시는 **"결과"**, 설계 레버는 **"원인"** — 연결해서 사고.
- 분석 창마다 **특정 수차에 민감** — 용도에 맞는 표시 선택.
- **MTF는 종합**, 개별 표시는 **원인 추적**용.
