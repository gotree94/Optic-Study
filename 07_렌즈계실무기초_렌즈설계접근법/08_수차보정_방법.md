# 8. 수차보정 방법

> 2일차 4강 · 수차별 실질적 보정 기법 총정리

## 8.1 보정 방법 분류

| 분류 | 기법 |
|------|------|
| **설계(구조)** | 곡률, 간격, Stop, 장 수 |
| **재료** | Glass 배합, 비구면 |
| **비축상** | 자유곡면 |
| **시스템** | 소프트 보정, 센서 |

## 8.2 수차별 보정 방법표

| 수차 | 대표 보정법 | 비고 |
|------|-----------|------|
| **구면수차** | ① 렌즈 분할(장↑) ② 비구면 ③ f/#↑ | 비구면은 1장으로 강력 |
| **혼장** | ① Stop 이동 ② 대칭 배치 ③ 주변부 최적화 | 광각에서 심화 |
| **난시** | ① Stop 위치 ② 비축상 요소 제거 | — |
| **포면** | ① 분산 조합 ② 렌즈 간격·배열 | Petzval 합 관리 |
| **혼성** | ① 대칭성 ② Stop | 혼장과 유사 |
| **지마** | ① Stop 이동 ② 소프트 보정 | 측정용은 엄격 |
| **축상 색수차** | ① 이중초점 ② Glass ΔV↑ | 기본 |
| **횡색수차** | ① Glass 배합 ② 시야 제한 | 주변부 |

## 8.3 통합 보정 전략

```
[3차 수차 분해] → [주도 수차 식별] → [레버 선택] → [최적화] → [잔여 수차 평가]
```

| 단계 | 질문 |
|------|------|
| 1 | 무엇이 가장 큰 문제인가? |
| 2 | 어느 레버가 가장 효과적인가? |
| 3 | 다른 수차와 트레이드오프는? |
| 4 | 제작성·비용이 허용하는가? |

## 8.4 트레이드오프 예시

| 조작 | 이득 | 손해 |
|------|------|------|
| f/# 올림 | 구면↓, 심도↑ | 밝기↓, 회절 |
| 장 수 ↑ | 수차↓ | 무게·비용·미광 |
| 비구면 | 구면↓ | 가공·검사 비용 |
| Stop 이동 | 혼장↓ | 왜곡·FOV 변화 |
| 고굴절 | 소형화 | 분산·비용 |

## 8.5 실무 정리

- 수차 보정은 **단일 공식이 아니라 조합의 예술**.
- **주도 수차부터** 공략해야 효율.
- 모든 보정은 **트레이드오프** — 시스템 요구로 선택.
