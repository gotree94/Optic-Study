# 1. 렌즈란 무엇인가 (기능과 역할)

> 1일차 1강 · 렌즈의 본질적 기능 이해

## 1.1 렌즈의 정의

> 빛을 **굴절**시켜 원하는 위치에 상을 맺히게 하는 광학 부품.

| 광학 부품 | 역할 |
|-----------|------|
| **렌즈** | 굴절 (굴절률 차이) |
| **거울** | 반사 |
| **프리즘** | 굴절+내부 반사, 경로 변경 |
| **회절광학** | 회절 (Grating 등) |

## 1.2 렌즈의 기능

| 기능 | 설명 | 예 |
|------|------|-----|
| **집광** | 평행광을 초점에 모음 | 콘덴서 |
| **상 맺힘** | 대상의 상을 생성 | 카메라 |
| **배율** | 상을 확대·축소 | 현미경 |
| **포인팅** | 빛을 특정 방향으로 | 조명 |

## 1.3 굴절 기초 — Snell의 법칙

```
   n1·sinθ1 = n2·sinθ2
   
  공기(n=1)에서 유리(n=1.5)로: 빛이 축 쪽으로 꺾임
```

| 개념 | 의미 |
|------|------|
| **굴절률 n** | 매질의 빛 느림 정도 |
| **분산** | n이 파장에 따라 다름 → 색수차 |
| **전반사** | 밀도 큰→작은 매질, 임계각↑ |

## 1.4 볼록·오목 렌즈

| 유형 | 형상 | 기능 | 초점 |
|------|------|------|------|
| **볼록(양의 렌즈)** | 중앙 두꺼움 | 수렴 | 실제 초점 |
| **오목(음의 렌즈)** | 중앙 얇음 | 발산 | 허상 초점 |

```
볼록:            오목:
  ╭──╮            │    │
 │    │          ╰──╯
  ╰──╮          (양쪽 오목)
```

## 1.5 렌즈의 역할 — 시스템 내 위치

```
[대상] → [수집 렌즈] → [이미징 렌즈] → [센서]
          ↑ 광선 모음     ↑ 상 맺힘
```

| 단계 | 렌즈 역할 |
|------|----------|
| 앞단 | FOV·수집 결정 |
| 중간 | 수차 보정 |
| 끝단 | 상 크기·품질 결정 |

## 1.6 실무 시사점

- 렌즈는 "잘 만들어진 유리"가 아니라 **"원하는 광선을 원하는 곳으로 보내는 도구"**.
- 설계는 **수집→보정→상 맺힘** 3단 구조로 사고.
- 이해를 위해 **레이 다이어그램**을 항상 그릴 것.
