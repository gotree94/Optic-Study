# 5. 렌즈설계 Process

> 2일차 1강 · 효율적 설계 진행 프로세스

## 5.1 설계 프로세스 개요

```
[1. 요구사항 정의] → [2. 초기 구조 탐색] → [3. 최적화] → [4. 평가] → [5. 공차·제작성] → [6. 검증]
```

## 5.2 단계별 상세

### Step 1: 요구사항 정의

| 항목 | 예 |
|------|-----|
| FOV, f/#, 초점거리 | 시스템 제약 |
| 해상도/MTF | 성능 목표 |
| 왜곡, 색수차 | 응용별 |
| 크기·질량·비용 | 실장 제약 |
| 센서·파장 | 하드웨어 정합 |

### Step 2: 초기 구조 탐색

| 방법 | 설명 |
|------|------|
| **Patent/카탈로그** | 기존 설계 참고 |
| **Petrov, Connal 등** | 고전적 초기 구조 |
| **Scaling** | 유사 설계 축소/확대 |
| **경험** | 유형별 휴리스틱 |

### Step 3: 최적화

| 항목 | 내용 |
|------|------|
| **Merit Function** | RMS spot, MTF, 왜곡 등 |
| **변수** | 곡률, 두께, Glass |
| **제약** | 두께, 간격, f/# |
| **알고리즘** | Local → Global/Hammer |

### Step 4: 평가

| 지표 | 확인 |
|------|------|
| MTF | 중앙/주변 |
| Spot Diagram | 점 상 |
| Distortion | 왜곡 |
| Chromatic | 색수차 |

### Step 5: 공차·제작성

| 항목 | 검토 |
|------|------|
| 두께·간격 공차 | 제작 가능 |
| Glass availability | 재고 |
| 비구면 여부 | 비용 |
| 조립 | 마운트 |

### Step 6: 검증

| 방법 | 내용 |
|------|------|
| **Monte Carlo** | 공차 시뮬레이션 |
| **Prototype** | 실물 제작 |
| **MTF 계측** | 실측 대조 |

## 5.3 효율적 접근 원칙

| 원칙 | 설명 |
|------|------|
| **요구사항 명확화** | 모호하면 재설계 반복 |
| **초기 구조 중요** | 나쁜 초기값은 최적화로 못 구함 |
| **간단히 시작** | 장 수, 비구면 최소화 |
| **병행 검토** | 설계-기계-제작 동시 |
| **데이터 기록** | 반복 학습 자산화 |

## 5.4 실무 정리

- 설계는 **"무엇을 만족시킬 것인가"가 정해져야 효율적**.
- 최적화만 믿지 말고 **좋은 초기값과 제약**이 핵심.
- **공차·제작성**을 나중에 붙이면 실패 — 처음부터 병행.
