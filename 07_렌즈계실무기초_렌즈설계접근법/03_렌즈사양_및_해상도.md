# 3. 렌즈사양 및 해상도

> 1일차 3강 · 사양표 읽기와 해상도 이해

## 3.1 주요 렌즈 사양

| 사양 | 정의 | 예 |
|------|------|-----|
| **초점거리(f)** | 초점까지 거리 | 25 mm |
| **f/#** | 초점거리/입사동경 | f/2.8 |
| **해상도** | 선 갈라보기 한계 | 100 lp/mm |
| **왜곡(Distortion)** | 기하 오차 | <0.1% |
| **FOV** | 시야각 | 30° |
| **BFL** | 후초점거리 | 12 mm |
| **배율** | 상/원물 | 0.5x |

## 3.2 해상도(Resolving Power)란

> 선을 **얼마나 가늘게 갈라 보이는지**의 한계.

| 단위 | 의미 |
|------|------|
| **lp/mm** | 선 쌍(line pair) 수 / mm |
| **cy/µm** | 사이클 / µm (센서와 관련) |

```
 1 lp/mm:  |■ □■ □|  (굵은 선)
 10 lp/mm: |■□■□■□|  (가는 선)
 → 선이 가늘수록 lp/mm ↑, 구분 어려움
```

## 3.3 해상도 결정 요인

| 요인 | 영향 |
|------|------|
| **렌즈 자체** | 수차, 회절 |
| **f/#** | 너무 열거나 닫으면 흐려짐 |
| **센서 픽셀 피치** | Nyquist 한계 |
| **파장** | 짧을수록 회절 해상도↑ |
| **거리·배율** | 대상 해상도 |

### Nyquist 관계

```
최대 유효 해상도 = 1 / (2 × 픽셀 피치)
예: 픽셀 3.45 µm → ~145 lp/mm
```

## 3.4 해상도와 MTF

| 지표 | 관계 |
|------|------|
| **해상도** | 한계 지점 (MTF=0 근사) |
| **MTF** | 주파수별 대비 — 더 풍부한 정보 |

```
MTF
1.0 ┤●━━━┓
    │     ┗━━━┓
0.5 ┤          ┗━━━━┓
    │               ┗━━●
0.0 ┼──┬──┬──┬──→ lp/mm
```

## 3.5 사양표 체크리스트

| 항목 | 확인 사항 |
|------|----------|
| 해상도(lpm) | 센서 픽셀과 정합 |
| f/# 범위 | 밝기·심도·해상도 |
| 왜곡 | 측정용 vs 영상용 |
| FOV | 대상 크기 |
| BFL | 카메라 마운트 |
| 온도 범위 | 환경 |

## 3.6 실무 정리

- **해상도는 렌즈·센서·조명·거리**가 함께 결정.
- 사양표는 **MTF 곡선과 함께** 봐야 신뢰.
- 설계·선정 시 **Nyquist와의 정합**을 먼저 확인.
