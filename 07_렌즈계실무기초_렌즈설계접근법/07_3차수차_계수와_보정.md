# 7. 3차 수차 계수와 수차보정의 기본

> 2일차 3강 · Seidel 계수로 수차를 분해·보정

## 7.1 3차 수차(Seidel)란

> 중심부 시야·소구경에서의 **1차 근사 수차**. 설계 초기 보정에 핵심.

| # | 계수 | 수차 |
|---|------|------|
| S I | S₁ | 구면수차 |
| S II | S₂ | 혼장 |
| S III | S₃ | 난시 |
| S IV | S₄ | 포면(Petzval) |
| S V | S₅ | 혼성(Coma) |
| — | — | 횡색수차 (Lateral color) |

## 7.2 Seidel 계수의 의미

```
각 렌즈 표면·재료가 각 수차에 "기여"를 함
전체 수차 = Σ 표면 기여
```

| 관점 | 활용 |
|------|------|
| **표면별 분해** | 어느 면이 문제인지 파악 |
| **Glass 영향** | n·V가 기여에 미치는 영향 |
| **Stop 영향** | Stop 위치가 계수를 바꿈 |

## 7.3 수차보정 기본 원리

| 수차 | 기본 보정 원리 |
|------|--------------|
| **구면(S₁)** | 렌즈 곡률 분산, 비구면, f/#↓ |
| **혼장(S₂)** | 대칭 배치, Stop 조정 |
| **난시(S₃)** | Stop, 비축상 최소화 |
| **포면(S₄)** | 분산 선택 (Petzval 합) |
| **혼성(S₅)** | 대칭성, Stop |
| **횡색** | Glass ΔV 배합 |

## 7.4 Glass 배합 기본 (이중초점)

```
[크라운 (V↑, n 중간)] + [플린트 (V↓, n 높음)]
  → 축상 색수차 상쇄
```

| 조합 원리 | 결과 |
|-----------|------|
| ΔV 큰 두 소재 | 강한 색수차 보정 |
| n 차이 | 굴절 분담, 구면수차 관리 |

## 7.5 Stop 위치의 설계 효과

| Stop 위치 | 효과 |
|-----------|------|
| **렌즈 앞** | 지마·혼장 변화 |
| **렌즈 뒤** | FOV·수집 변화 |
| **중앙** | 대칭성↑, 혼장↓ |

## 7.6 실무 정리

- 3차 수차는 **설계 초반의 나침반** — 전체 성능을 대표하지는 않으나 방향 제시.
- **표면별 Seidel 기여**를 보면 "누구를 고칠지"가 명확.
- Glass·Stop·곡률이 **3대 레버**.
