# 2. 렌즈계 구성 및 수차

> 1일차 2강 · 여러 렌즈의 조합과 수차 보정 개요

## 2.1 왜 렌즈계인가

| 단일 렌즈 한계 | 렌즈계 해결 |
|---------------|-----------|
| 구면수차 | 다장 조합으로 보정 |
| 색수차 | 이중초점 등 |
| 주변부 성능 | 배치 최적화 |
| FOV 확대 | 다연 설계 |

## 2.2 렌즈계 구성 요소

| 요소 | 역할 |
|------|------|
| **Object space** | 대상 |
| **Lens elements** | 굴절·수차 보정 |
| **Stop(Aperture)** | 광량·수차 제어 |
| **Image space** | 상/센서 |

### 렌즈 배치 유형

| 유형 | 예 | 특징 |
|------|-----|------|
| **싱글** | 단축 | 저렴, 수차 많음 |
| **이중( achromat)** | 2장 | 색수차 보정 |
| **트리plet** | 3장 | 종합 보정 |
| **복합계** | 다수 | 고성능 |

## 2.3 주요 수차 표

| 수차 | 증상 | 대응 |
|------|------|------|
| **구면수차** | 경계 흐림 | 비구면, 배합 |
| **혼장** | 상 깨짐 | 대칭 배치 |
| **난시** | 가로/세로 분리 | Stop 위치 |
| **포면** | 상 휘어짐 | 분산·배열 |
| **지마** | 왜곡 | 소프트, Stop |
| **색수차(축상)** | 색 테두리 | 이중초점 |
| **색수차(횡)** | 주변 색번짐 | 배합 |

## 2.4 Stop(Aperture)의 역할

| 기능 | 설명 |
|------|------|
| **광량** | f/# 결정 |
| **수차** | 주변 광선 차단으로 수차↓ |
| **심도** | f/# 높을수록 넓어짐 |
| **해상도** | 너무 작으면 회절 |

```
[대상] → [렌즈] → [Stop] → [상]
                ↑ 위치에 따라 수차·왜곡 변화
```

## 2.5 렌즈계 설계 관점

| 관점 | 고려 사항 |
|------|----------|
| **수집** | NA, f/#, Etendue |
| **보정** | 수차 예산 |
| **상** | 크기, 왜곡, 품질 |
| **제작성** | 두께, 간격, Glass |

## 2.6 실무 정리

- 렌즈계 설계는 **"몇 장을 어떻게 배치할 것인가"**의 문제.
- **Stop 위치**는 수차·왜곡·심도를 동시에 좌우하는 설계 레버.
- 수차를 **유형별로 분해해 사고**해야 효율적.
