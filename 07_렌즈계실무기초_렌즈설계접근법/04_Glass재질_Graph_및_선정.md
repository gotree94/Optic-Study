# 4. Glass 재질 Graph 및 선정방법

> 1일차 4강 · Glass Catalog와 Abbe Diagram으로 보는 재료 선택

## 4.1 Glass란

> 렌즈를 만드는 **광학 유리·재료**. n(굴절률)과 Abbe 수(분산)가 핵심.

| 재료 분류 | 예 |
|-----------|-----|
| **크라운(Crown)** | BK7, SK, BaK |
| **플린트(Flint)** | F, SF, LaF |
| **특수** | CaF₂, 실리카, 유리-세라믹 |

## 4.2 핵심 파라미터

| 파라미터 | 정의 | 의미 |
|----------|------|------|
| **굴절률 n_d** | d선(587.6nm) 기준 | 광선 꺾는 정도 |
| **Abbe 수 V_d** | 분산의 역수 | 낮을수록 분산↑ (색수차↑) |

```
Abbe 수 V = (n_d - 1) / (n_F - n_C)
  → 높음: 분산 낮음 (크라운)
  → 낮음: 분산 높음 (플린트)
```

## 4.3 Abbe Diagram (Glass Map)

```
     n_d (굴절률)
     ↑
 2.0 ┤        ●SF (플린트)
     │      ●
 1.7 ┤    ●LaK
     │   ●SK     ●BK7 (크라운)
 1.5 ┤  ●BK
     │ ●
 1.4 ┤●
     ┼────┬────┬────→ V_d (Abbe 수)
        20   40   70
     (분산↑)     (분산↓)
```

| 영역 | 특징 | 용도 |
|------|------|------|
| **크라운 (V↑)** | 분산 낮음 | 전면, 굴절 |
| **플린트 (V↓)** | 분산 높음 | 색수차 보정 |
| **고굴절 (n↑)** | 강한 굴절 | 소형화 |

## 4.4 선정 방법

### 기본 전략

| 목적 | 전략 |
|------|------|
| **색수차 보정** | 크라운+플린트 배합 (ΔV 큰 조합) |
| **소형화** | 고굴절(n↑) |
| **경량화** | 저밀도 소재 |
| **비용·재고** | 표준 Glass 우선 |
| **환경** | 내화학성, 용접성 |

### 선정 절차

```
[목표 n·V 범위] → [Abbe Diagram 후보] → [재고·비용 확인] → [내부 스트레스·화학성] → [최종]
```
