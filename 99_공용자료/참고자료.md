# 공용 참고자료 (Common Reference)

> 모든 교육과정 공통 참고 — 용어표, 소프트웨어, 표준, 추천자료

## 1. 핵심 광학 용어표

| 용어 | 영문 | 정의 |
|------|------|------|
| 굴절률 | Refractive Index (n) | 빛의 속도 변화 정도 |
| 초점거리 | Focal Length (f) | 초점까지 거리 |
| 조리개 | f-number (f/#) | 초점거리/입사동경 |
| 수차 | Aberration | 이상 상에서 벗어나는 오차 |
| MTF | Modulation Transfer Function | 대비 전달 기능 |
| 간섭계 | Interferometer | 파장을 자로 쓰는 계측기 |
| 자유곡면 | Freeform | 비축 대칭 표면 |
| 수치조리개 | Numerical Aperture (NA) | 빛 수집·해상도 지표 |
| 굴절 | Refraction | 매질 경계에서 진행 방향 변화 |
| 전반사 | Total Internal Reflection | 임계각 초과 시 완전 반사 |
| 분산 | Dispersion | 굴절률의 파장 의존성 |
| 시야각 | Field of View (FOV) | 촬영·관찰 범위 |
| 에틴두 | Etendue | 광선 용량 (면적×고체각) |
| 편심 | Decenter | 중심 정렬 오차 |
| 기울기 | Tilt | 표면 기울기 오차 |

## 6. 교육과정 간 연계 맵

```
[렌즈계실무기초] → [상용렌즈선정] → [기초광학평가]
       ↓                                    ↓
[기초광기구설계]                    [디스플레이색채공학]
       ↓
[적외선광학계설계] ←→ [LightTools기초및응용]
```

| 이수 권장 순서 | 이유 |
|---------------|------|
| 1. 렌즈계실무기초 | 광학 언어 기초 |
